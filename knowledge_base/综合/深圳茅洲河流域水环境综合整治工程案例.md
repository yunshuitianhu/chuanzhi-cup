# 深圳茅洲河流域水环境综合整治工程案例

## 污染概况

- **水体名称与位置**：茅洲河，广东省深圳市第一大河，干流长31.3公里，流域面积311平方公里（深圳境内），流经宝安区、光明区
- **主要污染物**：
  - 氨氮：峰值达22.8-23.3 mg/L（共和村断面）
  - COD：高浓度（劣Ⅴ类水平）
  - 总磷：超标严重
- **污染规模**：流域内44条黑臭水体、304个小微黑臭水体
- **治理目标**：全面消除黑臭，水质达到地表水Ⅳ类

## 综合整治工程参数

### 工程分类及规模
工程分为6大类：

| 工程类别 | 具体规模 |
|---------|---------|
| 管网工程 | 916 km |
| 河道综合整治工程 | 96.56 km |
| 排涝泵站工程 | 163 m³/s |
| 清淤工程 | 470万 m³ |
| 湿地工程 | 多处人工湿地 |
| 补水工程 | 生态补水系统 |
| 生态景观工程 | 碧道建设 |

### 具体子项目
- **排涝河截污工程**：位于宝安区沙井街道，治理河道总长4.3 km，其中黑臭水体治理长度3.45 km
- **界河段整治工程**：工程估算总投资10.53亿元
- **长安新区污水处理厂及配套管网工程**：已完成总工程量60%

## 治理效果

- **治理周期**：2015-2019年（约48个月）
- **氨氮下降**：共和村断面从23.3 mg/L降至1.15 mg/L（下降95.1%）
- **COD下降**：下降76.7%
- **总磷下降**：下降97.46%
- **综合污染指数**：下降92.28%
- **黑臭消除**：44条黑臭水体、304个小微黑臭水体全面消除黑臭
- **水质等级**：从劣Ⅴ类提升至Ⅳ类（达到1992年以来最好水平）
- **生态效益**：水清鱼跃，鸟类回归
- **社会效益**：入选2021年生态环境部美丽河湖优秀案例

## 关键经验

1. **全流域系统治理**：6大类工程同步推进，管网916km覆盖全流域
2. **超大清淤量**：470万m³清淤量，彻底解决内源污染
3. **高标准排涝**：排涝泵站总规模163 m³/s，解决内涝与水动力问题
4. **PPP模式融资**：引入社会资本解决资金问题

## 适用条件

- **适用水体类型**：流域性重污染河流、城市黑臭水体集中区域
- **限制条件**：投资规模巨大，需要政府强力推进和多部门协调
