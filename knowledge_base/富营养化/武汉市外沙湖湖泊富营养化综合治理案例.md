# 武汉市外沙湖湖泊富营养化综合治理案例

## 污染概况

- **水体名称与位置**：外沙湖，位于武汉市武昌区，是沙湖公园的重要组成部分，属于城中湖，水域面积约175万平方米
- **主要污染物**：
  - 总磷：超标率达100%（富营养化主要指标，峰值约0.5-1.0 mg/L）
  - 氨氮：超标率86-100%（峰值约5-10 mg/L）
  - COD：高锰酸盐指数超标（约20-40 mg/L）
  - 叶绿素a：偏高（藻类生物量指标，峰值>100 μg/L）
- **污染等级**：轻度黑臭，富营养化严重，蓝绿藻爆发，沉水植物近乎消亡，处于缺氧性环境
- **污染成因**：
  1. 数十年水产养殖污染累积
  2. 生活污水和工业废水排放污染
  3. 作为调蓄湖泊，汛期接收大东湖流域雨水调蓄后的水体
  4. 底泥释放营养物质
  5. 水体流动性差，自净能力弱

## 治理措施

1. **底泥疏浚工程**：
   - 2020年6月启动大规模湖水综合治理
   - 对湖底污染底泥进行清淤
   - 减少内源营养盐释放

2. **沉水植物种植（水下森林）**：
   - 种植近2万平方米的"水下森林"（沉水植物）
   - 栽种挺水植物20公顷、沉水植物171.92公顷、浮叶植物1.08公顷
   - 湖泊水生植被覆盖度由治理前的1.2%提升至治理后的60%以上
   - 沉水植物覆盖率达55.8%
   - 苦草、轮叶黑藻等沉水植物工程苗水下成活率达92%以上
   - 构建175万平方米"水下森林"

3. **生物操控与水动力改善**：
   - 调控264.7公顷水域鱼类资源
   - 投放肉食性乌鳢、黄颡鱼等鱼类
   - 投放螺、蚌等底栖动物
   - 构建完整的水下生态链
   - 在外沙湖雨水排口设置水动力装置，有效改善排口周边自净能力
   - 通过楚河与东湖连通

4. **精准清淤工程**：
   - 针对外沙湖特点，采用清淤与原位修复技术联合控制内源污染
   - 差异化采用精准清淤等手段
   - 减少内源营养盐释放

## 治理效果

- **治理周期**：2020年6月启动，2021年完成修复（约12个月）
- **总磷下降**：从约 0.8 mg/L 降至 0.1 mg/L 以下（下降87.5%，达到地表水Ⅲ类标准）
- **氨氮下降**：从约 8 mg/L 降至 1.0 mg/L 以下（下降87.5%，达到地表水Ⅲ类标准）
- **COD下降**：从约 30 mg/L 降至 15 mg/L 以下（下降50%，达到地表水Ⅳ类标准）
- **DO恢复**：从缺氧状态升至 5 mg/L 以上
- **叶绿素a**：从>100 μg/L 降至 <30 μg/L（下降70%以上）
- **黑臭消除**：是，2021年完成修复后整体水质达到Ⅳ类
- **水质等级**：从劣Ⅴ类/富营养化提升至Ⅳ类
- **生态效益**：
  - 沉水植物覆盖率达55.8%
  - 水面由蓝绿色变得清澈
  - 水下沉水植物生机勃勃
  - 岸边郁郁葱葱
  - 生态系统逐步实现自我维持
- **社会效益**：沙湖公园成为市民休闲娱乐的好去处，生态"明珠"得到擦亮

## 关键经验

1. **"三分靠治，七分靠养"**：治理完成后需要长期精细管护，确保生态系统稳定

2. **沉水植物为核心**：以沉水植物种植为核心手段，构建"水下森林"，通过植物吸收营养盐、抑制藻类生长

3. **完整生态链构建**：不仅种植植物，还投放鱼类、螺、蚌等，构建完整的水生生态链，实现生态系统的自我维持

4. **内源与外源共治**：既控制外源污染，又通过清淤减少内源释放，双管齐下

5. **城中湖特殊治理**：针对调蓄湖泊特点，在保障调蓄功能的前提下进行生态治理

## 适用条件

- **适用水体类型**：湖泊、水库、城中湖、缓流水体
- **适用污染程度**：富营养化、轻度黑臭、藻类爆发水体
- **限制条件**：
  - 需要较大的水域面积进行沉水植物种植
  - 治理周期较长，生态恢复需要时间
  - 需要长期管护，防止外来污染再次进入
  - 对于调蓄湖泊，需要协调防洪与生态功能
  - 初期需要人工干预，待生态系统稳定后可减少干预
  - 需要控制鱼类放养密度，避免破坏沉水植物
