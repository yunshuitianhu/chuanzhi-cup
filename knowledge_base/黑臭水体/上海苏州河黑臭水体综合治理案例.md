# 上海苏州河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：苏州河，位于上海市，是上海的母亲河，流经上海主城区，全长约125公里
- **主要污染物**：
  - 氨氮：超标严重（峰值约20-30 mg/L，超出黑臭判定标准15mg/L）
  - COD：超标（劣Ⅴ类水平，约80-150 mg/L）
  - 总磷：超标（约1.0-2.0 mg/L）
  - 溶解氧：极低（<1 mg/L）
  - 黑臭历史：从1920年开始黑臭，持续近90年
- **污染等级**：重度黑臭，是上海市历史最悠久、污染最严重的黑臭水体
- **污染成因**：
  1. 工业废水直排入河（历史上）
  2. 生活污水直排入河
  3. 河道淤积严重
  4. 水体流动性差
  5. 周边人口密集，污染负荷大

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除工业和生活污水直排

2. **污水处理厂建设**：
   - 新建和扩建污水处理厂
   - 提升污水处理能力
   - 实现污水全收集、全处理

3. **工业污染源治理**：
   - 关停并转污染企业
   - 工业废水达标排放
   - 从源头控制工业污染

4. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

5. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

6. **补水工程**：
   - 实施生态补水
   - 增加水体流动性
   - 提高水体自净能力

## 治理效果

- **治理周期**：1998-2012年（约14年）
- **氨氮下降**：从约25 mg/L降至<2 mg/L（下降92%，达到地表水Ⅳ类标准）
- **COD下降**：从约100 mg/L降至<20 mg/L（下降80%，达到地表水Ⅳ类标准）
- **总磷下降**：从约1.5 mg/L降至<0.3 mg/L（下降80%，达到地表水Ⅲ类标准）
- **DO恢复**：从<1 mg/L升至>4 mg/L（提升4倍以上）
- **黑臭消除**：是，2012年基本消除黑臭，结束近90年黑臭历史
- **水质等级**：从劣Ⅴ类提升至Ⅲ-Ⅳ类
- **生态效益**：
  - 河道生态环境恢复
  - 水生生物回归
  - 鱼类重新出现
- **社会效益**：
  - 成为上海市水环境治理的典范
  - 周边居民生活环境显著改善
  - 苏州河成为上海城市名片
  - 治理经验在全国推广

## 关键经验

1. **长期攻坚**：历时14年持续治理，体现"功成不必在我"的精神

2. **系统治理**：截污、处理、清淤、生态修复、补水多管齐下

3. **源头控制**：关停并转污染企业，从源头控制工业污染

4. **生态修复**：注重生态修复，构建健康水生态系统

5. **长效管理**：建立长效管护机制，防止返黑返臭

6. **历史传承**：兼顾历史文化保护，打造城市名片

## 适用条件

- **适用水体类型**：城市河道、历史名河、重污染河流
- **适用污染程度**：重度黑臭、劣Ⅴ类水体、长期污染水体
- **限制条件**：
  - 需要巨大的资金投入（数百亿元）
  - 需要多部门协调配合
  - 需要长期持续治理（10年以上）
  - 需要兼顾历史文化保护
  - 需要防止外来污染再次进入
