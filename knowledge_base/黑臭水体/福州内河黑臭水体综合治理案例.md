# 福州内河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：福州内河，位于福建省福州市，是福州市重点治理的黑臭水体，包括白马河、晋安河等多条内河
- **主要污染物**：
  - 氨氮：2010年达11.8 mg/L（超标约5倍，超过Ⅴ类标准2mg/L）
  - COD：2010年达70.83 mg/L（超标约77%，超过Ⅴ类标准40mg/L）
  - 总磷：超标
  - 溶解氧：极低
- **污染等级**：重度黑臭，氨氮指标超标1-3倍，是福州市重点治理的黑臭水体
- **污染成因**：
  1. 生活污水直排入河
  2. 河道淤积严重
  3. 水体流动性差
  4. 周边居民区和商业区污染
  5. 缺乏有效管理

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

3. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

4. **补水工程**：
   - 实施生态补水
   - 增加水体流动性
   - 提高水体自净能力

5. **景观提升**：
   - 整治河岸环境
   - 建设滨水景观
   - 打造市民休闲空间

## 治理效果

- **治理周期**：2010-2016年（约6年）
- **氨氮下降**：从11.8 mg/L降至2.99 mg/L（下降74.7%，达到地表水Ⅴ类标准）
- **COD下降**：从70.83 mg/L降至14.6 mg/L（下降79.4%，达到地表水Ⅳ类标准）
- **黑臭消除**：是，70%河道实现去黑除臭，白马河、晋安河等市区主干河道水质主要指标已基本达到地表Ⅴ类水质标准
- **水质等级**：从劣Ⅴ类提升至Ⅴ类
- **生态效益**：河道生态环境恢复，水体通透性明显改善
- **社会效益**：
  - 成为福州市黑臭水体治理的示范
  - 福州城区内河综合整治项目荣获2012年度全国人居环境范例奖
  - 晋安河从"水体黑臭"的"问题河"变成为水清岸绿可以福舟悠游、龙舟竞渡的旅游河

## 关键经验

1. **系统治理**：截污、清淤、生态修复、补水多管齐下

2. **源头控制**：从源头控制污染，消除污水直排

3. **生态修复**：注重生态修复，构建健康水生态系统

4. **景观提升**：结合城市景观建设，打造滨水休闲空间

5. **长效管理**：建立长效管护机制，防止返黑返臭

## 适用条件

- **适用水体类型**：城市内河、沿海城市河道
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要多部门协调配合
  - 需要长期持续治理
  - 需要考虑沿海城市潮汐影响
  - 需要防止外来污染再次进入
