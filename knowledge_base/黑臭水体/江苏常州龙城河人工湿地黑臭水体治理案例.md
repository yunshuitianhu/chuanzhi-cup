# 江苏常州龙城河人工湿地黑臭水体治理案例

## 污染概况

- **水体名称与位置**：龙城河，位于江苏省常州市，是常州市区重要的城市河道，全长约2公里
- **主要污染物**：
  - 氨氮：最高达 8 mg/L（超标4倍，远超地表水Ⅴ类标准2mg/L）
  - COD：超标（劣V类水平，约50-80 mg/L）
  - 总磷：超标（约0.5-1.0 mg/L）
  - 溶解氧：最低仅 0.2 mg/L（几乎无水生生物存活）
- **污染等级**：重度黑臭，曾是常州城区的"臭水河"，沿河居民满意度极低
- **污染成因**：
  1. 城市污水直排入河
  2. 河道淤积严重
  3. 水动力条件差，水体流动性不足
  4. 周边工业和生活污染源众多
  5. 生态系统破坏，自净能力丧失

## 治理措施

1. **人工湿地建设（核心措施）**：
   - 在龙城河畔建设占地120亩的人工湿地
   - 成为黑臭水体治理的"生态样板"
   - 采用土工膜作为防渗层（"隐形功臣"）
   - 湿地植物系统净化水质
   - 曝气设备：DO从0.85 mg/L升至8.81 mg/L

2. **土工膜应用**：
   - 在人工湿地底部铺设土工膜
   - 防止污水下渗污染地下水
   - 确保湿地系统高效运行
   - 延长湿地使用寿命

3. **截污纳管工程**：
   - 全面排查沿河排污口
   - 实施源头截污
   - 建设截污管道系统

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水下生态系统

5. **水动力改善**：
   - 实施活水循环工程
   - 增加水体流动性
   - 提高自净能力

6. **岸线整治**：
   - 整治河岸环境
   - 建设滨水景观
   - 打造市民休闲空间

## 治理效果

- **治理周期**：2018-2020年（约18个月）
- **氨氮下降**：从 8 mg/L 降至 1.5 mg/L 以下（下降81%，达到地表水Ⅴ类标准）
- **COD下降**：从约 60 mg/L 降至 20 mg/L 以下（下降67%，达到地表水Ⅳ类标准）
- **总磷下降**：从约 0.8 mg/L 降至 0.3 mg/L 以下（下降63%，达到地表水Ⅲ类标准）
- **DO恢复**：从 0.2 mg/L 升至 5 mg/L 以上（提升25倍）
- **黑臭消除**：是，治理1个月后河水已不黑不臭，达到"初见成效"标准
- **水质等级**：从劣V类提升至Ⅳ-Ⅴ类
- **生态效益**：人工湿地成为生态样板，生物多样性恢复
- **社会效益**：沿河居民满意度达到91%，成为市民休闲好去处

## 关键经验

1. **人工湿地为核心**：以人工湿地建设为核心治理手段，利用自然生态系统净化水质，成本低、效果好、可持续

2. **土工膜关键技术**：土工膜作为"隐形功臣"，解决了人工湿地的防渗问题，确保湿地系统高效稳定运行

3. **生态工程理念**：采用生态工程方法，模拟自然湿地生态系统，实现水质净化与生态修复双重目标

4. **因地制宜**：根据常州江南水乡特点，充分利用现有河网水系，建设人工湿地系统

5. **景观与功能结合**：将人工湿地建设与公园景观相结合，既治理了黑臭水体，又为市民提供了休闲空间

## 适用条件

- **适用水体类型**：城市河道、平原河网地区
- **适用污染程度**：重度黑臭、劣V类水体
- **限制条件**：
  - 需要一定的用地空间建设人工湿地（本案例120亩）
  - 需要专业设计和施工，确保土工膜铺设质量
  - 需要定期维护湿地植物系统
  - 对于寒冷地区，需要考虑冬季植物枯萎期的处理
  - 需要防止湿地堵塞，定期清理
  - 不适合用地紧张的城市中心区域
