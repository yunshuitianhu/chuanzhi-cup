# 扬州黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：扬州市主城区多条河道，包括大杨冲干河、东长河、老人沟等，是扬州市重点治理的黑臭水体
- **主要污染物**：
  - 氨氮：8-10 mg/L（超标4-5倍，超过Ⅴ类标准2mg/L）
  - COD：20-60 mg/L（部分超标，超过Ⅴ类标准40mg/L）
  - 总磷：超标
  - 溶解氧：极低
- **污染等级**：重度黑臭，是扬州市重点治理的黑臭水体
- **污染成因**：
  1. 生活污水直排入河
  2. 河道淤积严重
  3. 水体流动性差
  4. 周边居民区和商业区污染
  5. 缺乏有效管理

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

3. **曝气增氧**：
   - 安装曝气增氧设备
   - 提高水体溶解氧水平
   - 促进好氧微生物活性

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

5. **水动力改善**：
   - 增加水体流动性
   - 提高水体自净能力

## 治理效果

- **治理周期**：2018-2021年（约36个月）
- **氨氮下降**：从8-10 mg/L降至0.7-1.76 mg/L（下降76.5%-91.3%，达到地表水Ⅴ类标准）
- **COD下降**：从20-60 mg/L降至16-20 mg/L（下降20%-66.7%，达到地表水Ⅴ类标准）
- **总磷下降**：下降57.4%
- **高锰酸盐指数下降**：下降30.6%
- **氨氮指标下降**：下降81.1%
- **透明度**：从35.8厘米提高到47.6厘米
- **黑臭消除**：是，水质已达到五类水标准
- **水质等级**：从劣Ⅴ类提升至Ⅴ类
- **生态效益**：河道生态环境恢复，水生生物回归
- **社会效益**：
  - 先后对71条河道实施整治，累计投入资金23.5亿元
  - 成为扬州市黑臭水体治理的示范
  - 周边居民生活环境显著改善

## 关键经验

1. **多管齐下**：截污、清淤、曝气、生态修复综合施策

2. **严格验收**：按照消除黑臭标准严格验收

3. **生态修复**：注重生态修复，构建健康水生态系统

4. **长效管理**：建立长效管护机制，防止返黑返臭

## 适用条件

- **适用水体类型**：城市河道、支流河道、黑臭水体
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要多部门协调配合
  - 需要严格验收标准
  - 需要长期维护管理
  - 需要防止外来污染再次进入
