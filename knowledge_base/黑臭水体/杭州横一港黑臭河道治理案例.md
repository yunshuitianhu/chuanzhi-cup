# 杭州横一港黑臭河道治理案例

## 污染概况

- **水体名称与位置**：横一港，位于浙江省杭州市江干区九堡街道，是和睦港4条支流之一，东起和睦港，西至东湖路
- **主要污染物**：
  - 氨氮：超标严重（峰值约12-15 mg/L，超出黑臭判定标准）
  - COD：超标（劣Ⅴ类水平，约60-80 mg/L）
  - 总磷：超标（约0.8-1.0 mg/L）
  - 溶解氧：极低（<1 mg/L）
  - 透明度：<20cm
- **污染等级**：重度黑臭，是杭州市2016年重点治理的41条黑臭河道之一
- **污染成因**：
  1. 生活污水直排入河
  2. 河道淤积严重
  3. 水体流动性差
  4. 周边居民区和商业区污染
  5. 缺乏有效管理

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

3. **曝气增氧（微纳米气泡技术）**：
   - 采用微纳米气泡曝气技术
   - 提高溶氧效率
   - 安装曝气增氧设备
   - 提高水体溶解氧水平
   - 促进好氧微生物活性

4. **生物治理**：
   - 完成"沉水植物+水生动物+曝气"等综合生态修复工程
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

## 治理效果

- **治理周期**：2016年（约6个月，成为当年杭州首条"摘帽"黑臭河道）
- **氨氮下降**：从约12 mg/L降至1.5 mg/L（下降87.5%，达到地表水Ⅳ类标准）
- **COD下降**：从约70 mg/L降至<20 mg/L（下降71.4%，达到地表水Ⅳ类标准）
- **总磷下降**：从约0.8 mg/L降至0.16 mg/L（下降80%，达到地表水Ⅲ类标准）
- **DO恢复**：从<1 mg/L升至4.2 mg/L（提升4.2倍，超过消除黑臭标准2mg/L）
- **透明度**：从<20cm提升至>40cm（超过验收标准20cm）
- **黑臭消除**：是，顺利通过消除黑臭预验收，成为2016年杭州首条"摘黑帽"城市河道
- **水质等级**：从劣Ⅴ类提升至Ⅲ-Ⅳ类
- **生态效益**：河道生态环境恢复，水生生物回归
- **社会效益**：
  - 成为杭州市黑臭水体治理的示范
  - 周边居民生活环境显著改善

## 关键经验

1. **快速治理**：约6个月完成治理，成为当年首条"摘帽"河道

2. **多管齐下**：截污、清淤、曝气、生态修复综合施策

3. **严格验收**：按照消除黑臭标准严格验收（透明度>20cm，DO≥2mg/L，氨氮≤4mg/L，总磷≤0.4mg/L）

4. **生态修复**：注重生态修复，构建健康水生态系统

5. **长效管理**：建立长效管护机制，防止返黑返臭

## 适用条件

- **适用水体类型**：城市河道、支流河道、黑臭水体
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要快速实施，确保短期内见效
  - 需要多部门协调配合
  - 需要严格验收标准
  - 需要长期维护管理
  - 需要防止外来污染再次进入
