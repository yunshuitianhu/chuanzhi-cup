# 长沙圭塘河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：圭塘河，位于湖南省长沙市雨花区，发源于长株潭绿心石燕湖，汇入浏阳河，是长沙市重要的城市内河，周边居住着约200万人口
- **主要污染物**：
  - 氨氮：超标严重（峰值约12-16 mg/L，超出黑臭判定标准）
  - COD：超标（劣Ⅴ类水平，约60-80 mg/L）
  - 总磷：超标（约0.8-1.2 mg/L）
  - 溶解氧：极低
- **污染等级**：重度黑臭，曾因河道硬化、污水直排等问题成为黑臭水体
- **污染成因**：
  1. 河道硬化，生态功能丧失
  2. 生活污水直排入河
  3. 周边200万人口的生活污染
  4. 水体流动性差
  5. 缺乏有效管理

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口并实施截污
   - 截污率目标100%
   - 涉及范围包括圭塘河路两侧绿地宽度(含堤顶)合计约50米

2. **生态引水工程**：
   - 投资达1.6亿元用于圭塘河生态工程
   - 明年从浏阳河引水
   - 打通水系连通

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

4. **智慧监测系统**：
   - 建设水质监测站（圭塘河便桥站）
   - 配置COD、氨氮、总磷监测指标
   - 实时监控水质变化
   - 建立预警机制

5. **海绵城市理念**：
   - 雨花区多方位采用海绵城市建设理念
   - 采取系统整治
   - 实现中下游水体恢复

6. **长效管护机制**：
   - 建立河长制
   - 定期巡查维护
   - 防止返黑返臭

## 治理效果

- **治理周期**：2017-2019年（约24个月）
- **氨氮下降**：下降75%（从约12 mg/L降至<3 mg/L，达到地表水Ⅳ类标准）
- **COD下降**：下降60%以上（达到地表水Ⅳ类标准）
- **总磷下降**：下降90%以上（从约1.0 mg/L降至<0.1 mg/L，达到地表水Ⅱ类标准）
- **DO恢复**：升至正常水平
- **黑臭消除**：是，水质连续四个月稳定在Ⅲ-Ⅳ类，入河口水质持续稳定在Ⅲ-Ⅳ类
- **水质等级**：从劣Ⅴ类提升至Ⅲ-Ⅳ类
- **生态效益**：河道生态环境恢复，水清岸绿
- **社会效益**：
  - 长沙成为全国第一批城区黑臭水体治理达标城市
  - 圭塘河黑臭水体治理通过生态环境部、住建部专项督查
  - 治理经验在全国推介
  - 圭塘河畔成为市民休闲好去处
  - 成为新的网红打卡地

## 关键经验

1. **截污为根本**：从源头控制污染，消除污水直排

2. **生态修复为核心**：破除硬化河道，恢复生态功能

3. **智慧化管理**：建设水质监测站，实时监控水质

4. **系统治理**：截污、清淤、生态修复多管齐下

5. **群众参与**：建立河长制，发动群众参与护水

6. **长效机制**：建立防止返黑返臭长效机制

## 适用条件

- **适用水体类型**：城市内河、硬化河道、人口密集区河道
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要破除硬化河道，施工难度较大
  - 需要协调周边大量居民
  - 需要建设完善的监测系统
  - 需要长期维护管理
  - 需要防止外来污染再次进入
