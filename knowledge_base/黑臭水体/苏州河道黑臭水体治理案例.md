# 苏州河道黑臭水体治理案例

## 污染概况

- **水体名称与位置**：苏州市多条河道，包括蒋家浜小区东侧河道、青龙河等，是苏州市重点治理的黑臭水体
- **主要污染物**：
  - 氨氮：蒋家浜小区东侧河道氨氮浓度高达22.5 mg/L（超地表水Ⅲ类标准21.5倍）
  - COD：超标
  - 总磷：超标
  - 溶解氧：极低
- **污染等级**：重度黑臭，部分河道达到黑臭标准
- **污染成因**：
  1. 生活污水直排入河
  2. 工业废水排放
  3. 河道淤积严重
  4. 水体流动性差
  5. 源头治理亟待加强

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

3. **水系沟通**：
   - 打通水系连通
   - 增加水体流动性
   - 提高水体自净能力

4. **沿线环境综合整治**：
   - 整治河岸环境
   - 建设滨水景观
   - 打造市民休闲空间

5. **长效管护机制**：
   - 建立河长制
   - 定期巡查维护
   - 防止返黑返臭

## 治理效果

- **治理周期**：2017-2022年持续治理
- **氨氮下降**：从22.5 mg/L降至达标水平（下降90%以上）
- **黑臭消除**：是，到2025年全市城市黑臭水体实现动态清零，全市域内河道全面消除劣V类
- **水质等级**：从劣Ⅴ类提升至达标
- **生态效益**：河道生态环境恢复，水清岸绿
- **社会效益**：
  - 青龙河整治工程于2017年12月完工，总投资300余万元
  - 成为苏州市黑臭水体治理的示范
  - 周边居民生活环境显著改善

## 关键经验

1. **控源截污为根本**：从源头控制污染，消除污水直排

2. **水系沟通**：打通水系连通，增加水体流动性

3. **环境综合整治**：不仅治河，也治岸，实现水岸共治

4. **长效管理**：建立长效管护机制，实现黑臭水体动态清零

5. **目标导向**：制定明确目标，到2025年全市城市黑臭水体实现动态清零

## 适用条件

- **适用水体类型**：城市河道、江南水乡河道
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要多部门协调配合
  - 需要长期持续治理
  - 需要加强源头治理
  - 需要防止外来污染再次进入
