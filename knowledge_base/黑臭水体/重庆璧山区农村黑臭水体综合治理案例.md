# 重庆璧山区农村黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：璧山区农村黑臭水体，位于重庆市璧山区，包括29条农村黑臭水体
- **主要污染物**：
  - 氨氮：超标（黑臭判定标准为>15 mg/L）
  - COD：超标
  - 总磷：超标
  - 溶解氧：<2 mg/L（黑臭判定标准）
  - 透明度：<25cm（黑臭判定标准）
- **污染等级**：黑臭，是重庆市重点治理的农村黑臭水体
- **污染成因**：
  1. 农村生活污水直排
  2. 畜禽养殖污染
  3. 河道淤积严重
  4. 水体流动性差
  5. 缺乏有效管理

## 治理措施

1. **因水施策**：
   - 针对不同水体特点制定治理方案
   - 分类施策，精准治理
   - 提高治理效率

2. **截污纳管工程**：
   - 建设农村污水收集管网
   - 消除生活污水直排
   - 建设农村污水处理设施

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

5. **示范样板建设**：
   - 选择七塘镇喜观村、将军村开展"农村污水零直排"示范
   - 打造可复制可推广的治理模式
   - 以创促干、以奖促治

## 治理效果

- **治理周期**：2023-2024年
- **黑臭消除**：是，实现29条农村黑臭水体"动态清零"
- **氨氮**：平均值优于标准值
- **溶解氧**：平均值优于标准值（>2 mg/L）
- **透明度**：平均值优于标准值（>25cm）
- **水质等级**：全部完成治理，达到消除黑臭标准
- **生态效益**：农村水生态环境显著改善
- **社会效益**：
  - 成为重庆市农村黑臭水体治理的示范
  - 落实重庆市第6号总河长令
  - 持续深入打好净土保卫战

## 关键经验

1. **因水施策**：针对不同水体特点制定治理方案，分类施策

2. **动态清零**：建立"动态清零"机制，确保治理成果持续巩固

3. **示范引领**：打造示范样板，形成可复制可推广的治理模式

4. **以创促干、以奖促治**：通过创建和奖励机制推动治理工作

5. **长效管理**：建立长效管护机制，防止返黑返臭

## 适用条件

- **适用水体类型**：农村河道、农村坑塘、农村黑臭水体
- **适用污染程度**：黑臭水体
- **限制条件**：
  - 需要结合农村特点制定治理方案
  - 需要村民配合和参与
  - 需要建立长效管护机制
  - 需要防止外来污染再次进入
