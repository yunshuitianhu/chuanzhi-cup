# 广州市驷马涌城市河道黑臭水体治理案例

## 污染概况

- **水体名称与位置**：驷马涌，位于广州市荔湾区，是广州老城区重要的河涌之一，全长约1.8公里
- **主要污染物**：
  - 氨氮：重度超标（峰值约 10-15 mg/L，超标5-7倍）
  - COD：超标（劣V类水平，约 50-80 mg/L，超标约3-4倍）
  - 溶解氧：极低（<1 mg/L），透明度 <25cm
  - 总磷：超标（约 0.5-1.0 mg/L）
- **污染等级**：重度黑臭，曾"臭名昭著"，被列入广州市首批重点整治的35条黑臭河涌之一
- **污染成因**：
  1. 老城区排水管网老旧，雨污合流严重
  2. 生活污水直排入河
  3. 河道淤积严重，底泥释放污染物
  4. 水动力条件差，水体流动性不足
  5. 周边餐饮、商铺等污染源众多

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口，实施源头截污
   - 建设截污管道，覆盖主要排污口
   - 对沿河餐饮、商铺等污染源进行整治

2. **雨污分流改造**：
   - 对老城区合流制管网进行分流改造
   - 修复破损管网，减少外水混入
   - 优化排水系统布局

3. **底泥疏浚**：
   - 对河道进行全面清淤
   - 清除多年沉积的污染底泥
   - 减少内源污染释放

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物，构建水下生态系统
   - 设置生态护坡

5. **水动力改善**：
   - 实施活水循环工程
   - 增加水体流动性
   - 提高水体自净能力

6. **滨水环境整治**：
   - 整治河岸环境
   - 建设滨水绿道
   - 打造宜居空间

## 治理效果

- **治理周期**：2016年启动，2017年消除水体黑臭（约18个月）
- **氨氮下降**：从约 12 mg/L 降至 <2 mg/L（下降83.3%，达到地表水Ⅴ类标准）
- **COD下降**：从约 60 mg/L 降至 <20 mg/L（下降66.7%，达到地表水Ⅳ类标准）
- **总磷下降**：从约 0.8 mg/L 降至 <0.3 mg/L（下降62.5%，达到地表水Ⅲ类标准）
- **DO恢复**：从 <1 mg/L 升至 >4 mg/L（提升4倍以上）
- **透明度**：从 <25cm 提升至 >40cm
- **黑臭消除**：是，2017年消除水体黑臭，达到"初见成效"标准
- **水质等级**：从劣V类提升至Ⅳ类
- **生态效益**：重现水清岸绿，鱼鸟回归
- **社会效益**：周边居民生活环境显著改善，成为市民休闲好去处

## 关键经验

1. **"绣花"功夫精细治理**：针对老城区特点，采用精细化治理方式，不搞大拆大建，注重保护历史文化风貌的同时改善水环境

2. **水岸同治**：不仅治涌，也重视治岸，实现水岸共治，打造宜居空间

3. **源头治理优先**：从源头截污入手，减少污染物入河，而非简单的末端治理

4. **系统思维**：将河涌治理与城市更新、社区治理相结合，实现多重效益

5. **长效机制**：建立防止返黑返臭长效机制，确保治理成果持续巩固

## 适用条件

- **适用水体类型**：城市内河涌、老城区河道
- **适用污染程度**：重度黑臭、劣V类水体
- **限制条件**：
  - 老城区地下管线复杂，施工难度较大
  - 需要协调多方利益（居民、商户等）
  - 雨污分流改造投资较大
  - 需要长期维护管理
  - 对于历史文化街区，需要兼顾保护与治理
