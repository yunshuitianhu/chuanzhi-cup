# 南京秦淮河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：秦淮河，位于江苏省南京市，是南京的母亲河，流经南京主城区，全长约110公里
- **主要污染物**：
  - 氨氮：超标严重（2022年监测数据显示氨氮浓度超过15 mg/L，部分河段达7 mg/L以上，超过Ⅴ类标准2mg/L）
  - COD：高达68 mg/L（2022年监测数据，超过Ⅴ类标准40mg/L）
  - 总磷：超标
  - 溶解氧：极低
  - 透明度：不足0.2m
- **污染等级**：重度黑臭，除内秦淮河太平桥、復成桥两断面外皆属劣Ⅴ类水质，主要超标污染因子为氨氮和COD
- **污染成因**：
  1. 生活污水直排入河
  2. 工业废水排放
  3. 河道淤积严重
  4. 水体流动性差
  5. 周边人口密集，污染负荷大
  6. 秦淮区8成河流黑臭

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **污水处理厂建设**：
   - 新建和扩建污水处理厂
   - 提升污水处理能力
   - 实现生活污水全收集、全处理

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

5. **补水工程**：
   - 实施生态补水
   - 增加水体流动性
   - 提高水体自净能力

## 治理效果

- **治理周期**：2016-2018年持续治理
- **氨氮下降**：从超过15 mg/L降至0.994 mg/L（下降93.4%，达到地表水Ⅲ类标准）
- **COD下降**：从68 mg/L降至达标水平（达到地表水Ⅴ类标准）
- **水质等级**：从劣Ⅴ类提升至Ⅲ类
- **黑臭消除**：是，秦淮区8成黑臭河流得到整治
- **生态效益**：河道生态环境恢复，水生生物回归
- **社会效益**：
  - 成为南京市黑臭水体治理的示范
  - 周边居民生活环境显著改善
  - 秦淮河成为南京城市名片

## 关键经验

1. **系统治理**：截污、处理、清淤、生态修复、补水多管齐下

2. **源头控制**：建设污水处理厂，从源头控制污染

3. **生态修复**：注重生态修复，构建健康水生态系统

4. **长效管理**：建立长效管护机制，防止返黑返臭

5. **景观提升**：结合城市景观建设，打造滨水休闲空间

## 适用条件

- **适用水体类型**：城市河道、历史名河、人口密集区河道
- **适用污染程度**：重度黑臭、劣Ⅴ类水体
- **限制条件**：
  - 需要巨大的资金投入
  - 需要多部门协调配合
  - 需要长期持续治理
  - 需要兼顾历史文化保护
  - 需要防止外来污染再次进入
