# 云南宣威城区6条水体黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：宣威城区6条水体（包括东河、中沟河等），位于云南省宣威市城区
- **治理规模**：
  - 6条水体被列入国家黑臭水体治理监管平台
  - 中沟河长3.2公里，为重度黑臭
  - 排水管网老旧破损、雨污分流不彻底
- **主要污染物**：
  - 氨氮：进水浓度约20-25 mg/L（重度超标，超过黑臭判定标准15mg/L）
  - COD：进水浓度约150-200 mg/L（劣Ⅴ类水平）
  - 总磷：超标（约0.8-1.5 mg/L）
  - 溶解氧：极低（0.5-1.5 mg/L）
- **污染等级**：重度黑臭，水质长期处于劣Ⅴ类，透明度<25cm，成为城市发展的"生态伤疤"
- **污染成因**：
  1. 排水管网老旧破损
  2. 雨污分流不彻底
  3. 污水收集能力不足
  4. 生活污水直排入河
  5. 河道发黑发臭，底泥淤积严重

## 治理措施

1. **污水处理厂建设工程**：
   - 实施城镇污水处理提质增效项目
   - 建设北盘江流域水环境综合整治PPP项目
   - 北盘江流域水环境综合治理项目总投资23.74亿元
   - 涵盖污水收集处理、垃圾收运处置、河道防洪清淤、海绵城市建设等七大工程
   - 提升污水处理能力和收集率

2. **截污纳管工程**：
   - 实施月牙湖污水管网建设工程
   - 铺设截污管道76.6公里
   - 铺设雨水排水管道19公里
   - 全面排查沿河排污口
   - 消除生活污水直排口
   - 消除生活污水收集处理设施空白区
   - 提高生活污水集中收集率

3. **雨污分流改造**：
   - 对老旧管网进行雨污分流改造
   - 修复破损管网
   - 优化排水系统布局
   - 提高污水收集效率

4. **清淤疏浚**：
   - 对6条水体进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

5. **生态修复**：
   - 恢复河道生态岸线
   - 宣威东河通过实施生态护坡、水质修复等工程
   - 种植水生植物
   - 构建水下生态系统
   - 提高水体自净能力

6. **活水循环与清水补给**：
   - 实施活水循环工程
   - 规划"控源截污、内源治理、活水循环、清水补给、生态修复"技术路线
   - 增加水体流动性

7. **长效管理机制**：
   - 成立城市黑臭水体治理工作领导小组
   - 建立定期巡查维护机制
   - 防止返黑返臭

## 治理效果

- **治理周期**：2020-2023年（约36个月）
- **氨氮下降**：从进水 24.25 mg/L 降至出水 1.37 mg/L（去除率94.3%）
- **COD下降**：从进水 182 mg/L 降至出水 16 mg/L（去除率91.2%）
- **总磷下降**：从进水约 1.2 mg/L 降至出水约 0.2 mg/L（去除率83.3%）
- **DO恢复**：从 0.5-1.5 mg/L 升至 4 mg/L 以上
- **黑臭消除**：是，截至2023年12月底6条黑臭水体整治措施全部完工，黑臭水体消除率达100%
- **水质等级**：从劣Ⅴ类提升至Ⅴ类及以上，部分水体达到Ⅳ类标准
- **生态效益**：河道生态环境恢复，水清岸绿
- **社会效益**：
  - 宣威东河沿岸成为市民休闲娱乐的理想去处
  - 城市面貌焕然一新
  - 完成"初见成效"评估
  - 为高原城市黑臭水体治理提供示范

## 关键经验

1. **"溯本清源"理念**：从源头治理入手，通过建设污水管网和污水处理厂，从根本上解决污水直排问题

2. **PPP模式应用**：采用PPP模式引入社会资本，解决资金问题，提高治理效率

3. **系统治理**：截污、处理、清淤、生态修复多管齐下，系统解决污染问题

4. **政府主导、部门联动**：成立专门领导小组，统筹协调各部门，形成治理合力

5. **提质增效**：不仅建设设施，更注重提高现有设施的运行效率和处理效果

6. **高原城市特点**：针对高原城市特点，采用适合的治理技术和管理措施

## 适用条件

- **适用水体类型**：城市河道、高原城市水体
- **适用污染程度**：重度黑臭、劣V类水体
- **限制条件**：
  - 需要较大的资金投入（总投资5.6亿元用于黑臭水体治理，北盘江流域项目23.74亿元）
  - 需要政府主导和部门协调
  - 需要引入社会资本（PPP模式）
  - 治理周期较长，需要分阶段实施
  - 需要建立长效管理机制
  - 对于高原城市，需要考虑高海拔、低温等特殊气候条件
