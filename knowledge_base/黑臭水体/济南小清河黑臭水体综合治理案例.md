# 济南小清河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：小清河，位于山东省济南市，是济南市重要的城市河道和泄洪通道
- **主要污染物**：
  - 氨氮：峰值达 25.04 mg/L（超标11.52倍，超过地表水Ⅴ类标准2mg/L）
  - COD：峰值达 161.2 mg/L（超标3.03倍，超过地表水Ⅴ类标准40mg/L）
  - 总磷：超标严重
  - 溶解氧：极低
- **污染等级**：重度黑臭，水质持续为劣Ⅴ类，夏季时河道一度臭气熏天，被称为戴着"黑帽子"的河流
- **污染成因**：
  1. 生活污水和工业废水直排入河
  2. 污水处理能力不足
  3. 河道底泥淤积严重，污染物释放
  4. 水体流动性差，自净能力弱
  5. 每天大量COD、氨氮流入河道

## 治理措施

1. **截污纳管工程**：
   - 建设完善的污水收集管网系统
   - 全面排查沿河排污口并实施截污
   - 消除生活污水和工业废水直排

2. **污水处理厂建设与提标改造**：
   - 新建和扩建多座污水处理厂
   - 对现有污水处理厂进行提标改造
   - 出水COD达到11.5 mg/L，氨氮0.04 mg/L，远优于国家一级A排放标准
   - 每天45万吨高标准出水流入小清河

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除多年沉积的污染底泥
   - 减少内源污染释放

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

5. **补水工程**：
   - 实施生态补水
   - 增加水体流动性
   - 提高水体自净能力

6. **景观整体改造**：
   - 整治河岸环境
   - 建设滨水景观
   - 打造市民休闲空间

## 治理效果

- **治理周期**：2015-2021年（约72个月）
- **氨氮下降**：从 25.04 mg/L 降至 0.15-0.3 mg/L（下降98.8%-99.4%，达到地表水Ⅲ类标准）
- **COD下降**：从 161.2 mg/L 降至 <20 mg/L（下降87.6%，达到地表水Ⅲ类标准）
  - 第一次治理：从161.2 mg/L改善至84.7 mg/L
  - 持续治理后：降至<20 mg/L
- **总磷下降**：降至 0.05-0.1 mg/L（达到地表水Ⅲ类标准）
- **DO恢复**：维持在 6.5-8.2 mg/L（达到地表水Ⅱ-Ⅲ类标准）
- **黑臭消除**：是，彻底摘掉"黑帽子"，彻底改变劣Ⅴ类"黑"历史
- **水质等级**：从劣Ⅴ类提升至Ⅲ类
- **生态效益**：
  - 鱼类安家，游来中华鳑鲏鱼
  - 水生态系统恢复
  - 适合垂钓活动
- **社会效益**：
  - 2021年济南水成绩再创佳绩
  - 成为市民休闲娱乐的好去处
  - 济南水质指数获全省"七连冠"

## 关键经验

1. **源头治理**：从污染源入手，建设污水处理厂，实现生活污水全收集、全处理

2. **高标准排放**：污水处理厂出水远优于国家一级A排放标准，为小清河提供优质补水

3. **持续攻坚**：经过多年持续不断整治，水质逐步改善

4. **系统治理**：截污、处理、清淤、生态修复、补水多管齐下

5. **生态与景观结合**：景观整体改造，打造滨水休闲空间

6. **长效管护**：建立长效管护机制，确保水质持续改善

## 适用条件

- **适用水体类型**：城市河道、重污染河流、工业和生活污水混合污染水体
- **适用污染程度**：重度黑臭、劣Ⅴ类水体、COD和氨氮严重超标水体
- **限制条件**：
  - 需要巨大的资金投入
  - 需要建设高标准的污水处理设施
  - 治理周期较长，需要持续攻坚
  - 需要多部门协调配合
  - 需要长期坚持，防止污染反弹
  - 需要大量生态补水
