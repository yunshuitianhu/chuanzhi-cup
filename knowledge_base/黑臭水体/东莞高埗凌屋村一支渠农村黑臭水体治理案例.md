# 东莞高埗凌屋村一支渠农村黑臭水体治理案例

## 污染概况

- **水体名称与位置**：凌屋村一支渠，位于广东省东莞市高埗镇凌屋村片区，是该片区7条内河涌之一，全长约1.5公里
- **主要污染物**：
  - 氨氮：重度超标（约15-20 mg/L，超出农村黑臭判定标准15mg/L）
  - COD：超标（劣V类水平，约60-80 mg/L）
  - 总磷：超标（约0.5-1.0 mg/L）
  - 溶解氧：极低（<1 mg/L），透明度<25cm
- **污染等级**：重度黑臭，河面漂浮油污、垃圾，出现轻度黑臭现象
- **污染成因**：
  1. 截污及雨污分流改造进度缓慢
  2. 生活污水直排入河
  3. 河道淤积严重
  4. 水动力条件差，"死水"不流动
  5. 缺乏有效管理维护

## 治理措施

1. **畅流活水工程（核心措施）**：
   - 建设"畅流活水"工程
   - 打通水系连通，让"死水"流动起来
   - 新建1座泵站（抽水规模3m³/s）
   - 新建2座水闸
   - 增加水体流动性，提高自净能力
   - 工程完工通水后，沿河居民纷纷点赞

2. **截污纳管工程**：
   - 新建1500米截污管网
   - 对沿岸18个排污口完成截污
   - 建设截污管道系统
   - 实施雨污分流改造
   - 消除生活污水直排口

3. **清淤疏浚**：
   - 实施河涌清淤清障
   - 累计清理淤泥2930立方米
   - 清除沉积的污染物
   - 减少内源污染释放

4. **雨污分流改造**：
   - 对合流制管网进行分流改造
   - 修复破损管网
   - 优化排水系统布局

5. **岸线整治**：
   - 清理河岸垃圾
   - 整治河岸环境
   - 建设生态护岸

6. **长效管护机制**：
   - 建立河长制
   - 定期巡查维护
   - 防止返黑返臭

## 治理效果

- **治理周期**：2021-2024年持续攻坚综合整治（约36个月）
- **氨氮下降**：从约 18 mg/L 降至 <8 mg/L（下降55.6%，达到消除黑臭标准）
- **COD下降**：从约 70 mg/L 降至 <30 mg/L（下降57.1%）
- **总磷下降**：从约 0.8 mg/L 降至 <0.3 mg/L（下降62.5%）
- **DO恢复**：从 <1 mg/L 升至 >2 mg/L（达到消除黑臭标准）
- **透明度**：从 <25cm 提升至 >25cm（达到消除黑臭标准）
- **黑臭消除**：是，2022年消除黑臭，2024年完成消劣目标
- **水质等级**：从劣V类提升至V类及以上
- **生态效益**：河道生态环境恢复，"死水"变"活水"
- **社会效益**：
  - 沿河居民生活环境显著改善
  - 曾经的"死水"流动起来，居民纷纷点赞
  - 成为农村黑臭水体治理的典型案例

## 关键经验

1. **畅流活水为关键**：通过打通水系连通，让"死水"流动起来，是解决农村黑臭水体的重要突破口

2. **持续攻坚**：黑臭水体治理不是一蹴而就的，需要持续攻坚、综合整治

3. **系统治理**：截污、清淤、活水多管齐下，系统解决污染问题

4. **问题导向**：针对"死水"问题，重点实施畅流活水工程

5. **防止返黑返臭**：建立长效机制，定期巡查维护，确保治理成果持续巩固

6. **群众参与**：工程完工后得到沿河居民点赞，说明治理效果得到群众认可

## 适用条件

- **适用水体类型**：农村河道、城市内河涌、水系连通的平原河网地区
- **适用污染程度**：重度黑臭、劣V类水体
- **限制条件**：
  - 需要有可连通的水系条件
  - 需要一定的地形高差或泵站提水实现水体流动
  - 需要协调上下游水系关系
  - 需要持续的资金投入进行维护
  - 对于完全封闭的"死水"，需要建设循环水系
  - 需要防止外来污染再次进入
