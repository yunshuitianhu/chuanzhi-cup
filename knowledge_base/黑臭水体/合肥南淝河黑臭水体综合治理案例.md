# 合肥南淝河黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：南淝河，位于安徽省合肥市，是合肥的"母亲河"，流经合肥主城区
- **主要污染物**：
  - 氨氮：严重超标（历史监测显示氨氮、COD、总磷等指标严重超标）
  - COD：严重超标
  - 总磷：严重超标（水体富营养化问题突出）
  - 溶解氧：极低
- **污染等级**：重度黑臭，从曾经的清澈见底转变为黑臭水体
- **污染成因**：
  1. 生活污水直排入河
  2. 工业废水排放
  3. 河道淤积严重
  4. 水体流动性差
  5. 周边人口密集，污染负荷大

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水直排

2. **污水处理厂建设**：
   - 新建和扩建污水处理厂
   - 提升污水处理能力
   - 开展深度除磷工作

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

4. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

5. **补水工程**：
   - 实施生态补水
   - 增加水体流动性
   - 提高水体自净能力

6. **河长制落实**：
   - 全面推进和完善河长制工作
   - 严格督查考核
   - 狠抓措施落实

## 治理效果

- **治理周期**：2018-2023年（约5年）
- **氨氮下降**：2021年1-11月氨氮浓度1.53 mg/L，2023年氨氮0.91 mg/L（达到地表水Ⅲ类标准）
- **COD下降**：2021年1-11月COD浓度16.22 mg/L，2023年COD 16 mg/L（达到地表水Ⅲ类标准）
- **总磷下降**：2021年1-11月总磷浓度0.213 mg/L，2023年总磷0.17 mg/L（达到地表水Ⅲ类标准）
- **水质等级**：2020年成功消除劣Ⅴ类，2021年均值达到Ⅳ类，2023年施口国考断面平均水质达Ⅲ类，为有监测历史以来最好水平
- **黑臭消除**：是，合肥一直保持城市建成区黑臭水体动态清零
- **生态效益**：河道生态环境恢复，水生生物回归
- **社会效益**：
  - 成为合肥市黑臭水体治理的示范
  - 南淝河流域干支流水环境治理显成效
  - 水质改善取得历史性突破

## 关键经验

1. **系统治理**：截污、处理、清淤、生态修复、补水多管齐下

2. **源头控制**：建设污水处理厂，开展深度除磷工作

3. **河长制保障**：全面推进河长制，严格督查考核

4. **持续攻坚**：多年持续治理，水质逐年改善

5. **长效管理**：建立长效管护机制，保持黑臭水体动态清零

## 适用条件

- **适用水体类型**：城市河道、母亲河、人口密集区河道
- **适用污染程度**：重度黑臭、劣Ⅴ类水体、富营养化水体
- **限制条件**：
  - 需要巨大的资金投入
  - 需要多部门协调配合
  - 需要长期持续治理
  - 需要建立完善的河长制
  - 需要防止外来污染再次进入
