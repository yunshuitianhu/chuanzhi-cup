# 安徽怀远大观塘农村黑臭水体治理案例

## 污染概况

- **水体名称与位置**：大观塘，位于安徽省蚌埠市怀远县大观村，是皖北地区典型的农村黑臭水体，水域面积约3000平方米
- **主要污染物**：
  - 氨氮：超标严重（峰值约15-20 mg/L，超出农村黑臭判定标准15mg/L）
  - COD：超标（约40-60 mg/L，超标约2-3倍）
  - 总磷：超标（约0.5-1.0 mg/L）
  - 透明度：极低（<25cm，水体发黑发臭）
- **污染等级**：重度黑臭，曾是村民"掩鼻而过"的臭水塘
- **污染成因**：
  1. 农村生活污水直排
  2. 种养废水（稻虾种养退水）排放
  3. 长期缺乏管理，垃圾堆积
  4. 底泥淤积严重，释放污染物
  5. 水体流动性差，自净能力弱

## 治理措施

1. **底泥清淤工程**：
   - 对水塘底泥进行全面清淤
   - 清除多年沉积的污染物
   - 减少内源污染释放

2. **植物净化系统（植物方阵）**：
   - 打造植物方阵，实现阶梯式净化
   - 种植水生植物吸收营养盐
   - 构建生态浮岛系统
   - 利用植物根系净化水质

3. **截污纳管**：
   - 建设农村生活污水收集管网
   - 截留生活污水和种养废水
   - 防止污染物直接进入水塘

4. **资源化利用闭环**：
   - 将稻虾种养退水直接用于果树灌溉
   - 把处理达标的水体底泥用作育苗基质
   - 实现"截污—转化—回用"闭环
   - 实现环境治理与资源循环的统一

5. **生态护岸**：
   - 建设生态护岸
   - 种植岸边植物
   - 防止水土流失

6. **长效管护机制**：
   - 建立承包经营机制
   - 引入村民参与管护
   - 让治理成果转化为村民实际收益

## 治理效果

- **治理周期**：2023-2024年实施治理（约12个月）
- **氨氮下降**：从约 18 mg/L 降至 <1.5 mg/L（下降91.7%，达到地表水Ⅲ类标准）
- **COD下降**：从约 50 mg/L 降至 <20 mg/L（下降60%，达到地表水Ⅳ类标准）
- **总磷下降**：从约 0.8 mg/L 降至 <0.2 mg/L（下降75%，达到地表水Ⅱ类标准）
- **透明度**：从 <25cm 提升至 >40cm
- **DO恢复**：从极低水平升至 >4 mg/L
- **黑臭消除**：是，黑臭现象彻底消除，达到"不黑不臭"标准
- **水质等级**：从劣Ⅴ类提升至Ⅳ-Ⅴ类
- **生态效益**：水塘生态环境恢复，水生植物生长良好
- **社会效益**：
  - 从"掩鼻而过"变为村民休闲场所
  - 治理成果转化为村民实际收益
  - 为全省农村黑臭水体治理提供示范
  - 被安徽省生态环境厅作为典型案例推广

## 关键经验

1. **"以用促治"理念**：将治理与资源化利用相结合，让治理成果产生经济效益，实现可持续治理

2. **阶梯式净化**：通过植物方阵实现阶梯式净化，提高净化效率

3. **闭环治理模式**：建立"截污—转化—回用"闭环，实现资源循环利用

4. **村民参与机制**：引入承包经营机制，让村民参与管护并从中受益，确保治理成果长期保持

5. **因地制宜**：根据农村特点，采用适合农村的技术路线，避免"高大上"但不实用的技术

6. **生态与经济双赢**：既解决了环境问题，又为村民创造了经济收益

## 适用条件

- **适用水体类型**：农村坑塘、农村河道、小型水体
- **适用污染程度**：重度黑臭、劣V类水体
- **限制条件**：
  - 需要结合当地农业生产特点设计治理方案
  - 需要村民配合和参与
  - 需要建立长效管护机制
  - 不适合大规模、高强度的工业污染水体
  - 需要一定的土地空间进行植物净化系统建设
  - 对于寒冷地区，需要考虑冬季植物枯萎期的处理
