# 温州平原河网黑臭水体综合治理案例

## 污染概况

- **水体名称与位置**：温州市平原河网，包括市区平原河网（含瑞安市）23个市控以上监测站位，是温州市重要的水系网络
- **治理规模**：
  - 5年消灭黑臭河627公里
  - 剿灭劣Ⅴ类小微水体2947个
  - 累计完成河道清淤1039万方
  - 拆除违建512万平方米
- **主要污染物**：
  - 氨氮：超标严重（2013年基准，峰值约8-12 mg/L）
  - 高锰酸盐指数：超标
  - 总磷：超标（2013年基准，峰值约0.6-0.8 mg/L）
  - 溶解氧：极低
- **污染等级**：重度黑臭
- **投资规模**：5年累计完成治水投资超1300亿元
- **污染成因**：
  1. 生猪养殖场污染
  2. 生活污水直排
  3. 工业废水排放
  4. 河道淤积严重
  5. 水生态系统破坏

## 治理措施

1. **截污纳管工程**：
   - 全面排查沿河排污口
   - 建设截污管道系统
   - 消除生活污水和养殖废水直排

2. **养殖场关闭取缔**：
   - 关闭取缔生猪养殖场
   - 减少养殖污染
   - 从源头控制污染

3. **清淤疏浚**：
   - 对河道进行全面清淤
   - 清除沉积的污染底泥
   - 减少内源污染释放

4. **水系连通**：
   - 打通水系连通
   - 增加水体流动性
   - 提高水体自净能力

5. **生态修复**：
   - 恢复河道生态岸线
   - 种植水生植物
   - 构建水生态系统

6. **长效管护机制**：
   - 建立河长制
   - 定期巡查维护
   - 防止返黑返臭

## 治理效果

- **治理周期**：2013-2018年（约60个月）
- **氨氮下降**：较2013年下降74.3%（达到地表水Ⅲ类标准）
- **高锰酸盐指数下降**：较2013年下降28.9%
- **总磷下降**：较2013年下降60.0%（达到地表水Ⅲ类标准）
- **黑臭消除**：是，5年消灭黑臭河627公里，剿灭劣Ⅴ类小微水体2947个
- **水质等级**：从劣Ⅴ类提升至Ⅲ类，稳定在Ⅲ类水水平
- **生态效益**：河道生态环境恢复，水清岸绿
- **社会效益**：
  - 饮用水源地水质100%达标
  - 市民感受到身边的河道环境有了明显改善
  - 成为浙江省黑臭水体治理的典范

## 关键经验

1. **源头治理**：关闭取缔生猪养殖场，从源头控制污染

2. **系统治理**：截污、清淤、生态修复、水系连通多管齐下

3. **长效管理**：建立河长制，定期巡查维护

4. **持续攻坚**：5年持续治理，消灭627公里黑臭河

5. **群众参与**：发动群众参与护水，提高环保意识

6. **严格考核**：按照化学需氧量、氨氮、总磷三个指标进行考核

## 适用条件

- **适用水体类型**：平原河网、农村河道、水系连通区域
- **适用污染程度**：重度黑臭、劣Ⅴ类水体、流域性污染
- **限制条件**：
  - 需要关闭大量养殖场，协调难度大
  - 需要长期持续治理
  - 需要大量资金投入
  - 需要多部门协调配合
  - 需要建立长效管护机制
