# 味精行业高浓度氨氮废水处理工程案例

## 污染概况

- **水体名称与位置**：华东地区某年产10万吨味精企业发酵工段高浓度废水
- **主要污染物**：
  - 氨氮：5200-5800 mg/L（进水平均5500 mg/L）
  - CODcr：22000-28000 mg/L（进水平均25000 mg/L）
  - 总氮：约5800 mg/L
  - B/C比：0.35-0.42（可生化性中等）
- **污染等级**：超高浓度工业废水，远超任何排放标准
- **设计处理规模**：2000 m³/d
- **排放标准**：《发酵类制药工业水污染物排放标准》（GB 21903-2008），氨氮≤15 mg/L、CODcr≤120 mg/L

## 治理措施

### 工艺路线
预处理除杂 → 蒸汽辅助吹脱预脱氮 → 改良A/O生化 → BAF深度处理

### 1. 预处理单元
- **格栅**：机械细格栅，栅隙3mm
- **沉砂池**：平流式，停留时间3min
- **气浮池**：溶气气浮工艺，投加PAC 200mg/L + PAM 5mg/L，反应时间15min，气浮停留时间30min，悬浮物去除率92%，出水浊度≤20NTU

### 2. 蒸汽辅助吹脱单元（核心）
- **调节池**：NaOH调pH至10.5-11.0，蒸汽加热水温至45℃，游离氨比例>85%
- **一级吹脱塔**：填料塔，填料高度6m，气液比3000:1，停留时间90min，氨氮去除率75%，出水氨氮降至1200-1400 mg/L
- **二级吹脱塔**：气液比2000:1，出水氨氮降至<300 mg/L
- **尾气处理**：稀硫酸吸收塔（浓度5%），吸收率98%，年回收硫酸铵约1200吨

### 3. 改良A/O生化单元
- **缺氧池（A池）**：有效容积8000 m³，停留时间96h，内循环比400%，投加甲醇补充碳源（C/N=4:1），反硝化速率0.3 kg NO3⁻-N/(m³·d)，总氮去除率60%
- **好氧池（O池）**：有效容积12000 m³，停留时间144h，DO稳定2.5-3.0 mg/L，微孔曝气盘氧利用率28%，硝化速率0.2 kg NH4⁺-N/(m³·d)，出水氨氮<30 mg/L
- **二沉池**：辐流式，表面负荷1.2 m³/(m²·h)，污泥回流比100%

### 4. BAF深度处理单元
- **填料**：火山岩，粒径3-5mm，滤层高度2.5m
- **气水比**：5:1，空床停留时间45min

## 治理效果

- **治理周期**：系统连续运行12个月
- **氨氮**：进水5500 mg/L → 出水11 mg/L，总去除率99.8%
- **CODcr**：进水25000 mg/L → 出水95 mg/L，总去除率99.6%
- **总氮**：进水5800 mg/L → 出水35 mg/L，总去除率99.4%
- **出水水质**：氨氮≤15 mg/L、CODcr≤120 mg/L，稳定达标

## 关键经验

1. **蒸汽辅助吹脱解决冬季效率问题**：环境温度0℃时仍保持70%以上氨氮去除率
2. **碳源精准投加**：基于在线监测动态调整甲醇投加量，较固定投加降低30%碳源消耗
3. **资源回收**：尾气吸收生成硫酸铵外售，年增收约180万元

## 适用条件

- **适用废水类型**：味精、食品加工等高浓度氨氮有机废水
- **适用氨氮浓度**：>1000 mg/L
- **限制条件**：需要蒸汽热源，运行成本较高，需配套尾气处理系统
