# 化工行业高效吹脱+折点氯化处理高氨氮废水工程案例

## 污染概况

- **水体名称与位置**：某颜料有限公司（年产氧化铁颜料92000吨，中国氧化铁行业最大企业）生产工艺废水和地面冲洗废水
- **主要污染物**：
  - 氨氮：1200 mg/L
  - pH：很低（大量使用铁屑、硝酸、硫酸）
  - Fe离子：高浓度
  - COD：较低
- **污染等级**：高浓度氨氮工业废水
- **设计处理规模**：3000 m³/d（即125 m³/h）
- **排放标准**：《污水综合排放标准》（GB8978-1996）一级排放标准

## 治理措施

### 工艺路线
调节池 → 中和沉淀 → 氧化沉淀 → CR池调pH → 高效吹脱塔 → 氯化塔（折点氯化） → 脱氯池 → 净水器 → 达标排放

### 1. 调节池
- **结构**：钢混结构，有效容积300 m³
- **停留时间**：2.4h
- **功能**：格栅拦截+曝气搅拌均和水质

### 2. 中和池
- **结构**：钢混结构，地下式，有效容积40 m³
- **停留时间**：0.3h
- **功能**：投加碱调节pH，曝气搅拌

### 3. 初沉池
- **结构**：钢混结构，半地下式，有效容积450 m³
- **停留时间**：3.6h
- **功能**：沉淀Fe(OH)₂

### 4. 氧化池
- **结构**：钢混结构，半地下式，有效容积300 m³
- **停留时间**：2.4h
- **设备**：罗茨风机+微孔曝气
- **功能**：将Fe(OH)₂氧化为Fe(OH)₃沉淀

### 5. 二沉池
- **结构**：钢混结构，半地下式，有效容积630 m³
- **停留时间**：5h
- **功能**：沉淀Fe(OH)₃

### 6. CR池（吹脱前调节）
- **结构**：混凝土结构，半地下式，有效容积480 m³
- **停留时间**：3.8h
- **功能**：调节pH至吹脱所需值

### 7. 高效吹脱塔（核心单元）
- **结构**：主体玻璃钢制，9级串联
- **规格**：Ф5800mm×12500mm 和 Ф4200mm×12500mm
- **运行控制**：进水pH控制为11.2
- **效果**：出水氨氮约65 mg/L（吹脱效率约94.6%）
- **尾气处理**：硫酸吸收，制成(NH₄)₂SO₄

### 8. 氯化塔（折点氯化）
- **结构**：钢结构衬胶防腐，Ф3200mm×6000mm，共1座
- **运行控制**：次氯酸钠与氨氮质量比1:7，pH控制在6.5-8.5
- **效果**：出水氨氮<15 mg/L

### 9. 脱氯池
- **结构**：钢混结构，半地下式，有效容积450 m³
- **停留时间**：5h

### 10. 净水器系统
- **沉淀区**：有效容积450 m³，停留时间5h
- **过滤器**：钢结构，环氧煤沥青防腐，Ф3m×5.25m，共2只，压力过滤

## 治理效果

- **氨氮**：进水1200 mg/L → 吹脱后65 mg/L → 出水<15 mg/L
- **吹脱效率**：约94.6%（进水pH=11.2时）
- **折点氯化效率**：将65 mg/L降至<15 mg/L
- **出水水质**：达到《污水综合排放标准》（GB8978-1996）一级标准

## 经济指标

- **工程总投资**：425.6万元（土建费138.3万元，设备费287.3万元）
- **运行成本**：11.30元/m³
  - 电费：1.74元/m³
  - 药剂费：9.52元/m³
  - 人工：0.04元/m³

## 关键经验

1. **物化组合工艺优于生化**：由于废水量大但COD较低，采用物化工艺避免了补充大量有机碳源的高成本
2. **高效吹脱专利技术**：9级串联吹脱塔，氨氮吹脱效果优于传统工艺
3. **折点氯化保底**：前级高效吹脱将氨氮降至65 mg/L后，折点氯化法才经济可行
4. **尾气资源化**：吹脱废气用硫酸吸收制成硫酸铵，避免二次污染

## 适用条件

- **适用废水类型**：化工、颜料、冶金等高氨氮低COD废水
- **适用氨氮浓度**：500-2000 mg/L
- **限制条件**：药剂成本较高（9.52元/m³），需要配套尾气处理系统，进水COD低时才经济
