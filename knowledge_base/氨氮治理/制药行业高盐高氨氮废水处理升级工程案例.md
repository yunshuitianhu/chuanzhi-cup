# 制药行业高盐高氨氮废水处理升级工程案例

## 污染概况

- **水体名称与位置**：北方某大型头孢类抗生素生产企业废水
- **主要污染物**：
  - 氨氮：1800-2500 mg/L（进水平均2200 mg/L）
  - CODcr：高浓度（具体数值未公布）
  - 盐分：11000 mg/L（高盐抑制微生物活性）
  - 抗生素残留：5-8 mg/L（头孢类）
  - B/C比：<0.1（可生化性极差）
- **污染等级**：高盐高氨氮有毒工业废水
- **设计处理规模**：800 m³/d
- **排放标准**：《制药工业水污染物排放标准》（GB 21904-2008）直接排放要求：氨氮≤15 mg/L、CODcr≤100 mg/L、盐分≤1000 mg/L

## 治理措施

### 工艺路线
MVR蒸发脱盐 → 铁碳微电解 → 两级吹脱 → 厌氧氨氧化（Anammox）

### 1. MVR蒸发脱盐单元
- **预处理**：陶瓷膜过滤（孔径0.1μm），去除悬浮固体
- **MVR蒸发器**：降膜式蒸发器，蒸发温度75℃，真空度-0.08MPa
- **蒸汽消耗**：仅0.05t蒸汽/m³水（传统蒸发的1/8）
- **固液分离**：蒸发浓缩液经离心分离得到工业盐（NaCl纯度98%），可外售
- **盐分去除率**：>90%，出水盐分降至<1000 mg/L

### 2. 铁碳微电解单元
- **反应池**：有效容积600 m³，停留时间18h
- **填料**：铁碳填料（Fe:C=1:1），填充率60%
- **pH控制**：3.5-4.0
- **曝气模式**：间断曝气（曝气1h停2h），DO维持0.5-1.0 mg/L
- **效果**：抗生素残留降解率85%，B/C比提升至0.25

### 3. 两级吹脱单元
- **一级吹脱**：pH调至11.0，气液比2500:1，停留时间60min，氨氮从2200 mg/L降至450 mg/L，去除率79.5%
- **二级吹脱**：pH优化至10.5，气液比1500:1，停留时间40min，出水氨氮降至<120 mg/L
- **尾气处理**：两级吸收系统（一级稀硫酸吸收+二级活性炭吸附），厂界氨气浓度≤0.2 mg/m³

### 4. 厌氧氨氧化（Anammox）单元
- **反应器**：IC内循环厌氧反应器，有效容积1200 m³
- **容积负荷**：1.0 kg NH4⁺-N/(m³·d)
- **启动驯化**：历时3个月，Anammox菌占比达35%
- **运行参数**：水力停留时间48h，反应温度35℃（余热回收维持），pH 7.8-8.2，ORP -550~-600mV
- **短程硝化协同**：前置缺氧段，DO=0.3-0.5 mg/L，将30%氨氮转化为亚硝酸盐

## 治理效果

- **氨氮**：进水2200 mg/L → 出水达标（<15 mg/L）
- **盐分**：进水11000 mg/L → 出水<1000 mg/L
- **抗生素残留**：降解率85%
- **吨水能耗**：较传统A/O工艺降低41%
- **曝气量节省**：60%
- **碳源节省**：100%（无需额外碳源）

## 关键经验

1. **盐-氮分步处理**：先MVR脱盐消除抑制，再生物脱氮
2. **厌氧氨氧化高效应用**：节省60%曝气量与100%碳源
3. **余热梯级利用**：MVR蒸发器余热用于维持Anammox反应器温度

## 适用条件

- **适用废水类型**：制药、化工等高盐高氨氮有毒废水
- **适用氨氮浓度**：>1000 mg/L，含盐量>1%
- **限制条件**：投资成本高（MVR系统），Anammox启动周期长（3-6个月），需要专业技术团队运维
