# 内置仿真示例数据

本目录收录六组程序生成的走航监测示例，供空项目直接体验图表、质控和阈值筛查。它们**不是现场实测**，也不是南京秦淮河、成都南河或杭州瓶窑镇河道的污染事实；路线只作地图位置参考。

当前为 **V2 卫星水面定线版本**。V1 的人工静态地图线没有正确贴合水面，已停用；`仿真数据/` 中的 V1 Excel 仅作历史资料，不再作为本目录的来源。

## 文件

| 文件 | 场景 | 用途 |
| --- | --- | --- |
| `S01_仿真_正常背景.csv` | 正常背景 | 零预警/零热点也是有效筛查结果 |
| `S02_仿真_单源持续排放.csv` | 单源持续排放 | 观察异常筛查、趋势和聚类；场景名不代表已成功反演 |
| `S03_仿真_双源持续排放.csv` | 双源持续排放 | 允许多个异常区域；热点数量不等于污染源数量 |
| `S04_仿真_单源两次间歇排放.csv` | 单源两次间歇排放 | 保留时间结构；读数变化仍受走航位置与时间影响 |
| `S05_仿真_双源氨氮与有机物耗氧.csv` | 双源、多指标耗氧 | 按实际字段解释指标，不把 CBOD 当 COD |
| `S06_仿真_正常水体加仪器异常与缺测.csv` | 正常水体叠加异常与缺测 | 检查原始缺测、插值、质控和合法零值的区别 |

`manifest.json` 由 `scripts/prepare_sample_data.py` 从实际 CSV 字节生成，记录文件哈希、大小、行数、列、时间范围和来源。接口只按 manifest 白名单读取，不接受任意路径。

## 来源与转换

- 路线来源：`scripts/generate_synthetic_monitoring.py` 的 V2 路线，按星图卫星影像可见水面人工定线；控制点和瓦片框架随脚本提交。
- V2 生成器输出逐点真值与六份工作簿载荷；本目录的 CSV 由同一载荷生成的工作簿经 `scripts/prepare_sample_data.py` 导出。
- 只读取「仿真走航数据」工作表；不导出隐藏真值、污染源参数或说明表中的自由文本。
- 转换脚本：`python scripts/prepare_sample_data.py`。默认不覆盖内容不同的既有 CSV；确认后可加 `--force`。V2 重建时使用 `--source-label` 与 `--version-prefix v2`。
- 转换保留行顺序、时间字符串、坐标、有效读数、零值和缺测空单元格；不使用生产加载器的插值结果反向导出。
- 加载器会另行生成 `__observed_*` 标记，区分原始观测与插值。CSV 中的空单元格不是 0，也不是插值观测。
- V2 CSV 的坐标应落在脚本路线 10 米范围内（生成器约 0.7 米位置噪声）；回归会检查这一点，防止退回 V1 对角线路线。

## 字段与单位

首批六份文件具有相同 12 列：

`时间, 氨氮(mg/L), 溶解氧(mg/L), 水温(℃), 经度, 纬度, 电导率, 化学需氧量(mg/L), 总有机碳(mg/L), pH, 电量(%), 浑浊度(NTU)`

其中电导率、化学需氧量、总有机碳在首批样本中留空；COD 没有独立模拟，不能用 CBOD 结果冒充。时间没有声明时区，按原始本地时间字符串解释。坐标为 WGS84；路线按卫星可见水面人工近似定线，**不是测绘中心线**，也不承诺定位精度。南京、成都、杭州三处地点只作地图参考，杭州河名未核实。

## 演示限制

- 所有污染、排放、水力参数和辅助字段均为人为设定，辅助字段未经现场率定。
- 不包含污染源真值坐标、真实负荷、隐藏答案或现场准确率结论。
- S01 的零热点是正常筛查结果，不表示检测失败；S03/S05 的多个热点也不代表多个真实污染源。
- 无视频；载入示例不会触发视频分析或付费模型调用。基础图表、质控和阈值筛查不依赖 DeepSeek Key。
- 手册与 manifest 只描述场景用途，不将场景名称当作算法识别成功的证明。

## 复现检查

```bash
# V1 历史源（不用于当前 V2 样本）
python scripts/prepare_sample_data.py
# 当前 V2 样本的路线一致性回归
python -m unittest discover -s tests -p "test_sample_catalog_regressions.py"
```

正式交付包只带本目录的标准 CSV、manifest 和本说明；原始 Excel 仍保留在开发工作区，不作为接口或浏览器可下载目录暴露。
