# 原版交互与污染扩散恢复记录

2026-10-18。对照用户提供的 `苗圃杯/提交文件/` 源码，恢复点位查询和扩散播放。

## 对照发现

原版 `app.py` 中的 `tool_generate_trace_map` 给每 30 个采样点中的一个绑定弹窗，包含采样时间、氨氮、DO、COD、浊度，热点和 Top5 另有详情。新版此前只保留热点、Top5 和不可点击的热力画布，普通点查确实遗漏。

原版 `build_animation.py`、`river_model/animation.py` 有时间轴、播放和地图浓度变化展示。当前项目仍会生成部分旧 HTML，但 Vue 页面没有播放入口。旧构建流程包含固定样本路径、特定河流默认配置、经验排放估计，以及按模型长度缩放 GPS 桩号；这些不能直接移回用户要求通用、可交付的版本。

## 恢复的功能

地图接口返回全部有效采样点。点击热力色带按屏幕距离命中附近真实采样点，立即弹窗，同时在图下显示详情；相邻或重合坐标的记录可按时间切换。返回时间、WGS-84 坐标、氨氮、DO、COD、浊度、pH、原始综合污染指数和等级。高德底图显示转换同步作用于命中坐标，原始记录仍按原坐标展示。远离采样点的点击不生成“实测值”。

DO=0 保留。关键指标的插值参考与原始观测分开显示，缺少实测关键指标时不计算点位污染指数。旧数据中的可选指标没有保存原始/插值标记，界面标为“记录值（无插值标记）”，不推定为实测。弹窗使用 DOM `textContent`，详情使用 Vue 转义。

新增原生 `PollutionPlayback`，在图表页地图下方、河道页污染事件结果下方均有入口。支持播放、暂停、上一帧/下一帧、拖动时间轴、复位、演示变速，切换氨氮、DO、CBOD；沿程浓度曲线与卫星地图同步。模拟断面和情景排放点可点击查看当前时刻浓度。地图复用同一套底图，播放器不依赖旧 Folium HTML/CDN。

播放器只读取当前会话已有的一维恒定流计算数组，不启动模型、不自动推定污染工厂、不套用固定河流。全时段固定颜色范围，低 DO 使用相反颜色方向；曲线纵轴固定于该结果范围，避免每帧自动缩放。抽帧保留起点、末时刻、排放边界两侧和浓度极值帧：默认至多 121 个均匀帧，加不超过 5 个关键帧。CBOD 不使用 COD 限值。

没有 GPS 或轨迹不足时，浓度曲线仍可播放；地图显示原因。GPS 使用当前项目轨迹的累计桩号，不按比例拉伸为整个模型；轨迹未覆盖模型长度时不显示地图模拟。起点、方向、GPS 和水力/反应参数仍需现场核实；地图线宽不表示二维扩散范围。

无模拟结果时提供河道模型入口和操作顺序；过期、非有限、错误时间顺序、潮汐结果和其他会话结果均不能冒充有效播放数据。切换指标/模型及卸载时中止请求、清理计时器。

## 使用

1. 刷新图表页，点击污染色带，在弹窗和下方详情中查看附近记录。
2. 河道页依次初始化、运行水动力和模拟污染事件，然后播放扩散；图表页也可加载已有结果。
3. 要直接体验，可导入本轮示例项目。切换前由既有项目机制保存当前项目，导入使用新的项目 ID。

前端检查命令（在 `frontend` 目录）：

```powershell
node --test tests/severityHeat.test.mjs tests/projectRestore.test.mjs tests/projectStore.test.mjs tests/riverViewRender.test.mjs tests/mapCoordinates.test.mjs tests/amapLayer.test.mjs tests/mapInteractionPlayback.test.mjs
```
