# 底图与河道页修复记录

2026-10-18。针对用户反馈的灰色地图背景与河道页面空白。

## 原因与修复

地图原来默认使用外部 Esri 卫星瓦片，高德 Key 只用于 POI/逆地理查询。实测一条 Esri 瓦片请求返回 HTTP 403；同机现有高德 Key 请求官方静态地图返回 HTTP 200、PNG。这说明“已配置 Key”与“当前底图实际用了该 Key”原先是两回事。

新增 `/api/maps/amap-static`，后端访问固定高德官方地址，Key 不进入前端 URL 或响应。图片验证类型与签名，限制响应体大小，设置超时、不跟随跳转；JSON 权限错误仅回传数字错误码及配置提示，不回传可能带 Key 的上游 URL/异常。60 秒内存缓存限制条数和总字节数。底图请求不创建分析会话。

配置高德时默认使用高德街道底图。Leaflet 保留平移缩放及覆盖物，视口变化后取一张官方静态图片；超大视口降低请求级别并等比例显示，服务参数不超过 1024×1024 与 1–17 级。旧请求取消，卸载后不应用迟到响应，替换/卸载时释放 Blob。提供加载状态、重试、Esri/OSM 备用选择；每种来源每轮自动尝试一次，全部失败时明确提示。备用服务仍依赖各自网络可达性。

高德显示使用 GCJ-02，轨迹、热力点、聚类、Top5 同时从 WGS-84 转换；切换来源时同步调整地图中心。原始监测数据和污染强度不改写。三地坐标与后端现有转换结果比对通过。图层开关不再强制重设视野。

河道页的模型控件被包在没有 Vue 条件指令的原生 `<template>` 中，浏览器将其视为惰性内容，导致只显示外面的适用范围说明。改为普通容器。原有参数建议、手工参数、初始化、水动力、污染事件区恢复渲染，断面数和时长输入约束与后端一致。新增实际 Vue 组件 SSR 检查，要求控件在正常 HTML 中输出，防止再次被隐藏。

## 配置与复现

高德需后端 `AMAP_KEY`，类型为 Web服务；静态地图权限、IP 白名单、额度与后端网络需可用。前端不保存 Key。参考[高德官方静态地图文档](https://lbs.amap.com/api/webservice/guide/api/staticmaps)。

在项目根目录执行：

```powershell
python -m unittest discover -s tests -p 'test_*regressions.py' -q
```

在 `frontend` 目录执行：

```powershell
node --test tests/severityHeat.test.mjs tests/projectRestore.test.mjs tests/projectStore.test.mjs tests/riverViewRender.test.mjs tests/mapCoordinates.test.mjs tests/amapLayer.test.mjs
npm run build
```
