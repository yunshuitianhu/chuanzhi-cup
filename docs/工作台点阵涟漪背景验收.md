# 工作台 Pattern Waves（2026-11-04）

用户要求将工作台背景替换为 [React Bits Pattern Waves](https://reactbits.dev/backgrounds/pattern-waves) 的 pond 预设，参数来自用户链接。采用官方 OGL/WebGL2 点阵光照和交互涟漪实现，移植 Vue 生命周期；作者 David Haz，许可证保留于 `frontend/src/vendor/react-bits-LICENSE.md`。复用已有 `ogl@1.0.11`，无新增依赖。

## 参数与范围

指定参数全部显式保存在 `frontend/src/utils/patternWaves.js`：

```json
{
  "preset": "pond", "pattern": "dot", "wave": "ripple",
  "markSize": 0.9, "shine": 0.5, "speed": 0.5, "direction": 35,
  "color": "#06b6d4", "spacing": 10, "depth": 0.6, "scale": 0.85,
  "cursorSize": 30, "cursorStrength": 0.45
}
```

其余沿用官方预设/默认项：黑色底、opacity=1、edges 淡出、fadeSize=0.5、contrast=1.2、light=0、鼠标交互及入场开启。颜色在着色器中使用归一化 RGBA。

工作台外壳中只有一个固定全视口背景，独立堆叠在业务内容后，`pointer-events:none`；四个业务页面共用。面板主表面调整为 78% 不透明，次表面 92%，侧栏 90%，导航 92%，以看见波纹并保持正文可读。仅覆盖工作台范围内的表面变量，不修改严重度颜色、首页或业务逻辑。

后台页签暂停动画，进入视口后继续；减少动态效果时由官方逻辑渲染静态帧，不运行持续波动/交互。无 WebGL2 或初始化未成功时保留 CSS 静态点阵。卸载清理观察器、事件、动画帧、纹理/渲染目标及 WebGL 上下文；上下文丢失时回到静态底层。
