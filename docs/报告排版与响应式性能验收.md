# Q09 报告排版、响应式与性能验收

日期：2026-10-23。范围为界面、安全排版、操作可达性与受控性能验证；不把本项通过写成现场准确率、溯源因果正确性或新的 Agent 评测。

## 改动

- Agent 回答使用固定版本 markdown-it 15.0.3 排版标题、列表、表格与代码；原始 HTML 保持文本，禁用自动图片加载，不加载 HTML 插件。限制链接协议，外部链接使用 noopener/noreferrer；工具日志和用户输入继续纯文本显示。保留“查看原文/排版阅读”和原有证据入口，未完成报告仍显示状态。
- 流式排版每 80ms 合并更新；排版完成后同步聊天滚动。超过 200,000 字符时保留全文并退回转义文本，避免无限解析；未截掉尾部记录。
- 桌面可折叠侧栏并记忆界面偏好；767px 及以下为项目抽屉，关闭后主区占满宽度。抽屉提供关闭按钮、背景遮罩、焦点循环、Esc 关闭、焦点恢复和背景 inert；不重新挂载上传控件。
- 四个页面的导航、面板头、表单、地图工具栏和河道参数支持窄屏；表格在自身容器滚动。修复污染口径对比图窄屏轴标签被裁切，增加键盘焦点和减少动画偏好支持。
- 地图将选中采样点放到独立图层；点击和附近记录切换不清除热力底层。显示坐标转换缓存随数据/底图失效；严重度栅格计算和色标未改动。
- 热力重绘事件按动画帧合并，卸载取消回调；ECharts 在接近视口时初始化、离屏保留最新配置并延后绘制，尺寸变更按帧合并，卸载仍释放实例。趋势图选项使用计算缓存，避免界面状态变化反复生成四份时间序列。
- 新排版及调度工具一并纳入 strict/checkJs；没有将全站类型覆盖范围夸大为全部 Vue 组件。

## 性能测量与代价

在本机Node中，以1805个合成屏幕点、900×548画布、26px半径、9次测量比较同一算法：单次栅格中位数124.3ms；同批3次立即重绘中位数405.2ms；同批3个调度请求合并为一次中位数134.2ms。5300字符报告15次解析中位数5.9ms。

这是受控事件批次的CPU测量，不是浏览器实际帧率或所有设备的提速比例。地图点选单次双动画帧观察为46.6ms，也不作为性能保证。平移、缩放或弹窗导致视口移动时，仍需正确重绘。未做像素降采样，没有改变污染指数或把渲染优化当成算法精度提升。

安全排版引入新的解析依赖和包体开销。构建JS合计gzip由345.8KiB变为389.0KiB；不是网络首屏耗时，路由已有按需加载。现有锁定依赖版本未变化；新增依赖详情见机器记录。

复跑前端门禁：在frontend目录运行 `npm ci`、`npm run check`。受控测量运行 `node scripts/benchmark_ui.mjs`，不使用固定耗时阈值作为CI门禁。机器记录：[ui_acceptance_20261023.json](validation/ui_acceptance_20261023.json)。解析器配置参考：[markdown-it官方说明](https://markdown-it.github.io/markdown-it/)。
