# 卫星底图与热力带改进记录

2026-10-18。根据用户提供的旧效果图片和 196 秒演示视频，抽取 5 个关键帧检查；约 49 秒处可见星图卫星图层已选中。旧效果的主要优点是遥感背景、较集中的沿线色带和较少的遮挡。

## 已完成

- 配置了现有 `CLOUD_TOKEN` 时优先加载星图官方卫星影像。新增固定上游同源代理 `/api/maps/starcloud/{z}/{x}/{y}`，前端和浏览器瓦片地址不包含 Token。卫星影像使用原生 XYZ 瓦片，可连续缩放、平移；保留高德街道图与其他备用来源。
- 代理限制缩放级别与行列范围，禁止任意上游地址和跳转，设置网络超时、1MB 单瓦片上限，校验 WEBP 类型与签名；缓存最多 96 张、16MB，按 Token 指纹区分。错误不回传带 Token 的上游异常或内容。底图请求不创建分析会话。
- 热力层从默认 48px 显示半径收窄到 26px；计算从每 2px 一个像素改为每 1px，清晰中心和柔和边缘分开控制。固定色标提高饱和度，深色卫星背景下颜色更清楚。
- 增加色带宽度和不透明度调节；调节显示强度不会改变对应的严重程度色值。重复采样不会累加成更严重的颜色。默认隐藏细轨迹线，勾选可显示，以免 GPS 细碎折线遮住色带。
- 图例缩小，说明移到地图下方；地图增高并提供全屏查看。

旧 Python 页面使用不带严重程度权重的 `HeatMap(black[['latitude','longitude']].values, ...)`，红色受异常点密度影响。本次沿用当前原始综合污染指数及固定色标，以同一份 1805 点数据作前后算法绘图对比，没有把旧版密度红色解释为严重程度。显示范围之外保持透明；实际观测中的明显空间断点仍保留，横向晕染不代表污染范围。

星图按官方墨卡托瓦片显示，覆盖物使用原始 WGS-84 显示坐标；高德仍采用 GCJ-02 显示转换。现场 GPS 精度和影像配准不因取图成功而得到验证。参考[星图官方影像 API 文档](https://datacloud.geovisearth.com/support/map/img)及[官方调用教程](https://open.geovisearth.com/service/qa-assistance/86)。

## 查看

刷新 `http://127.0.0.1:5173/charts`，底图选择“星图卫星影像”。“热力显示”可调整色带宽度和颜色强度；“全屏查看”适合比较沿线效果。卫星服务受 Token 权限、额度、覆盖与网络状态约束；失败时界面显示状态并尝试备用来源。
