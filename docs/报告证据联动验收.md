# Q04 报告证据联动验收

日期：2026-10-22。范围为报告取证与记录关联，不是现场污染准确率或责任归因验收。

## 完成内容

- 新成功回答保存本轮实际工具调用的开始/结束时间、参数、成功/失败/跳过状态及脱敏返回快照。原文以文本显示，超过30000字符明确截断；失败、跳过、停止或未调用的工具不补造成功依据。
- 数据摘要、筛查实际返回与服务器重算一致时，生成统计卡片。均值/有效数关联完整观测集合；极值关联精确极值原记录，保留并列极值和DO=0，排除带原始观测缺失标记的插值。
- 黑臭预警记录及聚类支持记录使用唯一输入记录ID，必要时使用唯一索引关联。无法唯一关联时提示重新检测，不猜测对应行。热点簇数明确不是污染源数。
- 点查显示采样时间、当前位置序号、导入记录ID、观测值、插值参考、清洗前读数与质控信息。有效GPS可跳转图表地图并高亮相同记录；缺失或插值GPS不提供定位。
- 数据值/属性、目标等级、规则版本、检测/视频/外部查询及模型内容形成快照指纹。展开、翻页、记录定位均核对当前条件；不匹配时只保留历史统计与当时的工具原文，不关联当前记录。
- 本轮RAG案例可查看标题、地点及实际检索返回。现有检索接口没有原文URL，界面如实提示，不生成虚构链接。案例与企业资料不能作为污染责任证明。
- 元数据随消息进入现有项目格式，不新增严格STATE_FIELDS字段；不依赖内存任务ID或运行版本计数。模型输出目录不参与指纹，迁移后同内容仍可核对；模型数组变化会失效。
- 历史无证据元数据的回答不追补；没有本轮数据摘要的回答不借用旧统计生成卡片。统计核对仅涵盖卡片，正文每句话和因果解释仍须复核。
