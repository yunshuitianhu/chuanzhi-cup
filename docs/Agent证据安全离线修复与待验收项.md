## 改动与发现

| 问题 | 当前处理 |
| --- | --- |
| 虚构/缩写/旧轮次引用可保存为完整答案 | 报告返回与Agent提交前核对本轮实际片段；格式为`[证据ID:完整ID]`，兼容旧方括号/反引号`.md_数字`。未知或不完整引用拒绝完成，不回显可疑ID |
| 大RAG结果丢失后端ok/data包装 | 兼容真实包装和旧裸结果；按完整JSON预算删减案例，保留字面片段。被删去的片段不给引用权限 |
| 报告内部检索没有进入外层证据链 | 成功报告返回实际参考到reference_sink，再加入本轮工具快照；旧搜索结果不再混入新报告的监测摘要 |
| 普通对话工具失败仍可能报完整成功 | 本轮发生工具失败时保守标为partial；即使后来重试成功也保留本轮发生失败的事实 |
| 假引用提示在刷新历史后消失 | 服务端保存脱敏后的error消息，不写入模型后续上下文；日志、SSE和历史均移除配置密钥 |
| top_k=0变成默认5、空引用字段可能崩溃 | Agent范围1~10；拒绝bool/小数/字符串；空列表/片段安全处理，仅保存合法字符串ID |
| 模型建议把DO=0按缺失处理、把质控突刺当预警、删除冲突记录 | 证据规则v7明确零值保留、质控不自动说明超标、冲突不撤销已有预警；加入真实后端反例。提示词不能代替完整语义审核 |
