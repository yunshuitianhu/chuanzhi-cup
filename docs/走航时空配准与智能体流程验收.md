# 走航时空配准与智能体流程验收（2026-10-21）

本阶段增加显式参考线、绝对时间原点和逐点情景对照，并实际复验智能体工具链。没有新增现场标签、实测水力率定或人工确认的流向/时钟信息，不报告现场准确率，不开放真实多源反演。

## 配准与地图

河道页新增“走航时空配准与情景对照”。参考线为WGS84的`[[纬度,经度],...]`，必须按模型上游至下游排列并由用户确认时间原点。支持粘贴独立参考线，或从当前记录选取单向航段作为候选；候选不是独立测绘线，也不证明水流方向。

采用分段局部切平面投影、球面距离比较和球面弧长桩号。每个参考线段最多20km、总长100km、最多500节点；单次最多20000条记录，投影工作量不超过500万对。该方法是局部近似，不替代精密测绘。分批计算以限制内存，不缩放参考线去凑模型河长。

同一位置的返航观测回到相同桩号，使用各自的采样时间。监测时间按显式IANA时区转UTC，模拟起点必须带日期和时区偏移；时钟修正定义为“记录时间＋修正秒数”。无完整日期、DST歧义或不存在的本地时间不会自动补值。距离/航速/歧义容差是排查设定，不能解释为仪器校准精度。

缺失或非原始GPS、原始测值缺失/被插值替代、离线过远、位置歧义、异常航速线索、超出模拟时间或桩号范围及重复时空观测均不进入对照误差统计。原始记录和模型数组不修改，DO=0等有效零值保留。页面提供排除原因及前20条明细，统计使用全部记录。

配置保存在既有项目`river_ui.alignment`内，不改变项目格式。恢复后以及模型变化后重新计算对照；不信任历史误差缓存。配准和模型更新会撤销旧报告的完成标记；新摘要与报告明确区分“用户提供的假设下计算”与独立核实。

扩散地图优先使用显式参考线。参考线不足以覆盖模型范围时只禁用地图叠加，保留沿程动画；不拉伸或外推。未配置时，一般单向轨迹仍只能作为未配准示意；有明显返航、坐标或时间问题则停止沿累计航程映射，提示先配置。轨迹审查是启发式，未触发提示不证明单向或GPS合格。

自动参数建议发现明显重复巡测/返航时拒绝把航程当河长，要求手工配置。其它轨迹的长度仍只是未配准航程建议；取消原来的“河长95%置信度”，来源改为`gps_track_unregistered`，页面明确标注。其它参数沿用已有来源评级，不代表统计置信区间。旧路径一致性检查随此语义更新，验证其余8项完整且未给未配准河长编造置信度。

## 智能体实际执行与修复

- 所有流式回合都检查结束原因：工具调用必须完整以`tool_calls`结束，最终回答必须以`stop`结束；达到轮次上限后的收口也检查。`length`、过滤或缺结束标记不能成为成功结果，截断工具参数不执行。
- 自动复跑不发送旧工具输出和旧报告上下文，聊天模式保留历史。数据版本变化时停止旧回合。
- 有视频时，报告要求本轮视觉分析与交叉印证均完成；交叉印证使旧摘要失效后，必须重新取得摘要。错误原因不再被通用“报告正文无效”覆盖。
- 报告生成本身也要求`stop`，生成报告的工具上下文上限从普通2000字符独立提高到12000字符，避免已生成报告被普通工具上限截去后半部分。
- 首次实际复核发现模型把原始样例首末约2.3km称为“接近”。新增明确的首末距离事实、确定性报告抬头和`evidence-2026-10-21-v3`规则；不能把一般规则或可能情况改写为本次事实。旧缓存按版本提示重新分析。

实际DeepSeek与原生工具完成三次检查，未替换用户项目：

1. S04 V2仿真：1801条，827个预警点、2个聚类。报告保持仿真身份；真实企业与国控归因查询由服务器跳过；RAG与报告生成成功。
2. 原始Excel无视频：1805条，1230个预警点、10个聚类，标识来源未独立核验。POI/国控/RAG实际执行；此轮发现上述空间措辞错误，不能把协议完成等同正文每句话都正确。
3. 原始Excel＋真实视频复验：每60秒抽帧，成功取得13帧，视觉分析、交叉印证、RAG和报告完成。第一次因摘要过期拒绝报告，智能体补取最新摘要后重试成功，最终`analysis_done=true`。最终报告按2319.45m陈述首末距离，不再称首末接近。视频偏移0秒只是未核实情景；一致率38.5%不能当检测准确率。解码器出现尾帧H264警告，未验全视频逐帧质量。

RAG确实加载768维模型并检索；报告包含参考资料抬头，但案例只用于治理方法。完整工具执行事件与报告保存在本任务输出目录，仓库内只记录汇总与复跑程序。LLM正文仍需要人工复核，流程门槛不能证明所有因果解释均正确。
