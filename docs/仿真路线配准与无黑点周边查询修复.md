# 仿真路线配准与无黑点周边查询修复

2026-10-18。用户指出S01热力带没有贴合实际河道，并且正常对照无法在技术页运行多渠道查询。

## 已确认的问题

V1的三条人工地图描线没有完成卫星水面的配准验证。此前接口和工作表能正常运行、地图线能画出来，均不足以证明线在水上。这一地理验证遗漏同时影响共用路线的其他场景，因此V1不再用于地图演示或地理定位验证。

技术页按钮直接依赖`has_black_spots`。S01正常对照预期无黑点，因此按钮一直禁用，即使填了手动坐标也不能查询。后端原先也只会从有效热点推断中心，没有轨迹代表采样点的回退。采样弹窗还缺少最小宽度和最大高度，文字容易挤成长条。

## 修复

- 三条路线改为以实际星图卫星可见水面重新人工定线，记录zoom16瓦片世界像素原点与折线控制点，由同一明确框架生成WGS84。不改动真实监测样本，不给出测绘精度保证。
- 路线长度与采样位置变化后，重新运行全部六个场景的守恒输移/反应模型及走航采样；交付V2及独立真值，旧计数不套用到V2。用最终Excel坐标反投影到实际卫星瓦片核对，避免只核对控制点、交付表却偏移。
- 技术页允许有效手动坐标，或已加载数据时自动取中心。后端优先有效热点，之后采用实际有效走航记录中的代表点，不用弯曲河道的经纬度均值构造岸上点。返回中心来源及“周边背景资料”用途说明。
- 经纬度须完整成对，缺测、空字符串、0和非法值分别处理；半径为50~50000米整数。本次半径不再隐式改写会话分析配置。输入错误返回422，不会静默换位置。
- 数据版本变化时清除旧查询显示，迟到结果不混入新数据；点查弹窗设置最小宽度、最大高度及滚动。
