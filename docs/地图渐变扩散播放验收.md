# 地图渐变扩散播放验收

日期：2026-11-05。

## 行为

污染模拟播放器优先展示地图。初始帧只保留假定排放点；播放后，沿已配准河道绘制当前帧的渐变色带，采用圆角、玫红高光和柔光边缘，视觉参考 React Bits Pixel Trail。沿程总浓度曲线改为可展开查看。

色带以首个返回帧为初始值：氨氮、CBOD显示正浓度增量，DO显示下降量。比例上限取本次接口返回的全部播放帧，播放时不逐帧归一化。可视下限为 `max(1e-8, 最大增量 × 1e-5)` mg/L，仅控制显示，不是水质判定阈值。节点之间线性显示，低于可视下限的区段裁切。

每帧重画当前值，不累积历史画布；回退、复位、浓度回到初始值时会清除旧色带。地图移动、缩放和尺寸变化触发重绘，卸载时取消绘制任务并释放图层。

## 范围

- 沿用当前模型结果和既有河道配准检查，没有修改求解器、模型数组、源项、API契约或项目存储。
- 地图色带是相对初始值的变化，包含背景输移和反应等影响，不等同于独立源贡献；其固定像素线宽不表示二维污染面积。
- 没有有效河道配准时提示原因，提供按模型桩号绘制的扩散示意图及沿程曲线，不补造地理坐标。假定排放点不作为已识别污染源。
- 后端可能抽取播放帧；本次新增的增量色标基于返回帧，不声称覆盖未返回帧的增量极值。
