# 水质独立网格与分辨率改进记录

日期：2026-10-20。本轮解决水质与水动力共用最多100个断面时的数值分辨率限制，不扩展潮汐或真实来源反演。

## 已完成的修改

- 水动力仍使用原断面；每个区间可独立细分为1、2、4、8段水质网格，节点数为`(水动力断面数-1)×细分数+1`。100个水动力断面对应100、199、397、793个水质计算节点。
- Web/API及Agent河道工具默认4倍。河道页可选择原网格对照或8倍精细复算，无需重新运行水动力。源位置仍取最近水质节点，展示实际计算桩号和偏移，不声称精确定位任意源。
- 面积A与流量Q在原水动力节点之间线性插值，细分流速取Q/A；经验弥散系数在原水动力节点计算后插值。所有原水动力节点保留，A沿程的梯形积分不变。细分没有增加实测几何信息，也不能修复原水动力场本身的误差。
- 保留原守恒迎风面通量、排放时段交集注入及耦合反应内核，继续由对流/扩散共同约束实际子步。结果记录水动力节点数、水质节点数、细分数、间距、实际子步和计算量上界。
- 原生扩散播放、逐点时空采样、浓度剖面和项目包使用水质结果自身的桩号轴。旧项目没有细分参数时恢复为1倍，避免把历史结果显示成新默认精度；未运行的新项目默认4倍。改变细分数后需重新运行水质。
- 同一排放使用不同细分数时保存为不同情景名；节点统计明确随网格变化，不能把细分后的更多超标节点解释为更多实测断面或更大污染。

选择独立网格是为了直接复用已核验的守恒输移路径。本轮未引入高阶通量格式，也未声称消除了迎风格式的数值弥散。

## 独立解析对照

运行`scripts/validate_wq_refinement.py`，固定100个均匀水动力断面，改变水质细分数。参考为有限时段点源的解析Green函数卷积，并对每个水质控制体积积分；不以同一个求解器加密后的结果充当真值。源负荷1kg、源位在L/3且网格对齐，关闭氨氮反应，远场边界在污染云团之外。

请求积分步长均为60s，实际稳定性子步随网格改变。因此以下是整体正演误差对照，不是只改变空间步长的阶数估计，也不是现场检测准确率。

| 河段 | 水宽/水深/流速 | 1倍分布误差 | 2倍 | 4倍（默认） | 8倍 |
| --- | --- | ---: | ---: | ---: | ---: |
| 3km | 15m / 1m / 0.15m/s | 19.864% | 11.971% | 6.156% | 3.156% |
| 6km | 30m / 2m / 0.20m/s | 18.098% | 10.131% | 5.453% | 2.800% |
| 12km | 60m / 2.5m / 0.30m/s | 12.243% | 6.550% | 3.365% | 1.710% |

分布误差定义为体积加权相对L1误差。三组4倍结果均低于预设8%门限、8倍均低于5%，4倍误差均小于原网格的60%；峰值误差也降低。各组独立积分的最终氨氮质量均在1kg的1e-9kg以内，浓度非负，原水动力数组没有被修改。

三组时长分别为300/600/1200s，排放开始为11/37/73s，排放持续为30/60/120s。它们是短时内核独立基准，不能冒称网页最短0.5h请求本身的解析验收。真实Web接口另按允许时长验证如下。

## 接口、保存及计算成本

使用FastAPI TestClient执行真实路由和原生求解器，单独临时项目目录，不访问外部LLM、不修改已有项目绑定。

1. 手工初始化6km河段、100个断面，运行0.5h恒定流水动力。
2. 分别请求1倍、遗漏字段（采用默认4倍）、8倍的污染模拟。返回100/397/793个水质节点；均实际生成四张模型PNG，浓度剖面与原生播放接口200。
3. 保存8倍设置并导出项目包，恢复后水动力仍100节点、水质793节点；浓度数组逐项一致，表单及结果诊断一致。
4. 同一均匀水动力、默认50断面/1km/6h受控性能算例，保留实际反应项，原网格约0.80s，4倍197节点约9.55s，8倍393节点约34.27s（不含绘图）。这是本机一次计时，不是跨机器性能保证。

为防止更细网格把显式扩散计算放大到不可用，开始积分前以水动力A/Q包络计算子步上界。最多200000子步上界、5000万节点更新、800万个组分输出数值；细分结果最多1201节点。超过限制明确拒绝并建议降低细分数、缩短时长或增大输出间隔，不静默退回粗网格。

数学内核`solve_water_quality`默认仍为1倍，以保持旧CLI合成/反演实验的明确口径；需要新网格时传`wq_refinement=4`或8。新Web默认4倍并不意味着旧CLI反演已经验收了新精度。一次与修改前HEAD内核的对照中，显式原网格路径的时间、桩号、CBOD、NH3-N、NO3-N、DO六个数组逐位相同，质量账本相同。
