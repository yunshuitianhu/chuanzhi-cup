## 3. N05-B 给队友的异机验收流程

### 3.1 接收与准备

1. 接收 r2 ZIP，先核对 SHA-256：
   ```powershell
   Get-FileHash '.\delivery_20261028_r2.zip' -Algorithm SHA256
   ```
   应为 `7577E57813350D10281144D9C1751E37D2E92A16C353364681B334192A3602E2`。
2. 解压到新的中文且带空格目录；不要复制开发机 `.env`、用户项目、`.rag_index/` 或模型缓存。
3. 确认 Python 实际路径和版本，创建新 venv。以下 `$taskPython`、目录、端口都换成接收方实际值。

```powershell
$taskPython = 'C:\接收方的实际Python目录\python.exe'
& $taskPython --version
Set-Location 'D:\接收方 目录\传智杯交付'
& $taskPython -m venv '.venv-core'
& '.\.venv-core\Scripts\python.exe' -m pip install -r 'requirements-ci.txt'
& '.\.venv-core\Scripts\python.exe' -m pip check
& '.\.venv-core\Scripts\python.exe' 'scripts/serve_web.py' --check --port 5174
& '.\.venv-core\Scripts\python.exe' 'scripts/serve_web.py' --port 5174
```

每条命令检查退出码；端口占用时换空闲端口，不自动终止队友已有进程。不要把代理密码或 Key
写进共享日志。r2 已含构建后的前端，不要求另装 Node/Vite。
