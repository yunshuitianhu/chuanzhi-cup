## 1. 实现

在 `frontend/src/views/ChatView.vue` 顶部增加紧凑工作台条，四项对应任务要求的链路：

| 项 | 来源 | 动作 |
| --- | --- | --- |
| 数据 | `status.has_data/rows/data_identity` | 跳到「数据与示例」；无数据时显示“等待数据” |
| 当前问题 | `questionContext`、`textQuestions.pendingMain`、`chatDraft` | 聚焦输入框；自动分析不伪造用户问题 |
| 分析进度 | `agentRun` 阶段/状态、`status.analysis_done/has_detection` | 运行中查看进度；有数据未筛查时开始自动分析；已筛查查看图表 |
| 证据 · 下一步 | `status.black_spot_count`、`has_detection` | 打开现有排查板；无数据时跳到示例入口 |

同时：

- `DataPanel` 的示例区增加 `id="data-samples"`，工作台可直接定位。
- `AgentProgress` 外层增加 `id="agent-progress"`，运行中可从工作台回到进度。
- 工作台不新建第二套状态；所有值来自现有 store 和会话/revision。
- 保留四页导航、主聊天、Q13 上下文卡、Q14 划词/侧边问答、Q15 结构化卡片与排查板。

## 2. 单轮真实流程

环境：隔离项目目录 `work/browser_projects_q16c`，服务 `scripts/serve_web.py` 5187，生产构建；示例为 S01 V2（1801 行、`synthetic`）。

1. 空项目：工作台显示 `未载入数据 / 未提出 / 尚未分析 / 等待数据`。
2. 载入 S01：`1801 条记录 · 仿真 / 未提出 / 已完成基础筛查 / 0 个预警点`。
3. 点击「开始自动分析」：调用配置的 DeepSeek 服务，实际执行 26 秒、11 次工具调用；报告生成，但有 1 项未恢复失败——当前干净环境缺 `chromadb`/`sentence_transformers`，治理案例检索不可用。运行状态如实显示「部分完成」，不是成功。
4. 报告正文列出缺测指标、配准未设置、视频跳过和 RAG 失败，并给出复测建议；显示 4 张待确认研判卡片（草稿，未写入排查板）。
5. 失败后「从当前数据重新执行上一请求」入口可见；本轮未重复点击，避免无意义收费调用。
