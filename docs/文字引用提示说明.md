# 文字引用返回提示改进

日期：2026-10-27。

从对话“核对来源”返回时，URL携带临时引用标识。查询站点等操作更新结果版本后，旧引用不能代表当前结果；重启服务或恢复项目也可能使临时链接无法查询。本轮保留后端原有项目/版本核对，仅修改前端呈现与恢复操作。

- 409或客户端版本不匹配：说明先前引用对应较早项目/结果，提示重新选中文字。
- 404：说明之前的文字链接已失效，提示重新选择；不把原因断言为重启。
- 无效标识：不请求API，提示重新选文。
- 网络或其他加载失败：提供重试，不直接显示服务端内部错误正文。
- 普通提示替代全局红色报错，提供关闭入口；关闭只移除text_context，保留页面、其他查询参数、锚点和草稿。迟到请求与切换项目保护保留，未绕过版本核对。

验证：335项前端测试（本轮新增11项）、既有类型检查与生产构建通过。本轮未修改Python代码，不声称重跑全部Python测试。实际浏览器验证旧链接显示说明、关闭后URL清理、刷新/切页不再复现提示。项目“111”重启前保存为v10并导出，重启后1805条数据、147帧和历史对话保留；主/侧边输入框重启前为空。本轮没有发起新的模型问答。
