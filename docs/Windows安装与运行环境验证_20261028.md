## 4. RAG 依赖与缓存边界

- 干净 CI 环境缺少 `chromadb`、`sentence_transformers` 时，启动预检给出明确警告，不把基础服务判为启动失败。
- 共享环境已安装并可导入：chromadb 1.5.8、sentence-transformers 5.5.1、torch 2.10.0+cu128；本轮**没有**执行实际语义检索、模型下载或离线隔离检索。
- 索引目录默认 `.rag_index`；可用 `WQ_RAG_INDEX_DIR` 指定，模型可用 `WQ_EMBEDDING_MODEL` 指定。只复制 Chroma 数据库不等于完整离线 RAG：还需匹配的嵌入模型、依赖和向量维度。
- 首次实际检索或构建索引且缺缓存时可能下载数百 MB 模型；下载、模型加载、索引构建和实际检索是四个阶段，接口以 `stage` 区分，前端显示“依赖检查/索引读取/索引构建/模型加载/实际检索”。
