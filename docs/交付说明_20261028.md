## 3. 安装与运行

### 3.1 环境

| 项 | 实际验证值 | 要求 |

| 操作系统 | Windows 11 Home China 10.0.26200 | Windows 10/11 |

| Node.js | 24.15.0 | 仅重新构建前端需要；运行已构建版本不需要 |
| 浏览器 | Playwright Chromium（验收） | 现代 Chromium/Firefox/Safari 未逐一验证 |

### 3.2 安装依赖

完整运行（含 Streamlit、ChromaDB、嵌入模型等可选依赖）：

```bash
python -m pip install -r requirements-lock.txt
```

仅离线核心回归/示例/手工模型（不含 Streamlit 与 RAG 可选依赖）：

```bash
python -m pip install -r requirements-ci.txt
```

注意：

- 产品锁使用 `opencv-python`，CI 使用 `opencv-python-headless`；同一环境只装一种。
- 清华镜像只加速 PyPI，不保证模型权重下载加速：
  `python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-lock.txt`
- 本地 RAG 需要匹配的嵌入模型、依赖和索引；只复制 Chroma 数据库不等于完整离线 RAG。
  首次实际语义检索或构建索引且缺缓存时可能下载数百 MB 模型。

### 3.3 启动

推荐单服务（网页与 API 共用一个端口）：

```bash
python scripts/serve_web.py --port 5174
```

或 Windows 双击/命令行：

```bat
start_web.cmd
```

打开 `http://127.0.0.1:5174/`。如果端口被占用，换一个端口并同步使用新地址。
指定解释器：

```bat
rem CMD
set "WQ_PYTHON=C:\实际安装目录\python.exe"
start_web.cmd
```

```powershell
# PowerShell
$env:WQ_PYTHON = 'C:\实际安装目录\python.exe'
& '.\start_web.cmd'
```

启动前可只做预检，不启动服务：

```powershell
$env:WQ_PYTHON='E:\实际安装目录\python.exe'
cmd /c '"E:\E-Desktop\传智杯-备赛\start_web.cmd" --check --port 5199'
```

预检会区分“前端构建、API 导入、项目目录、端口、RAG 依赖缺失”等阶段；RAG 依赖缺失只警告，不判整个服务不可启动。

### 3.4 无 Key 体验示例

1. 打开页面，左侧「数据与示例」会列出 S01—S06。
2. 点「载入」或「载入并检测」。
3. S01 是正常背景：**0 个预警点是有效结果，不是检测失败**。
4. S02 会得到预警点和聚类；S06 保留缺测与仪器异常，用于检查质控标记。

示例载入、图表、质控、阈值筛查和手工恒定流情景**不需要模型 Key**。

### 3.5 启用 AI / 地图 / RAG

复制 `.env.example` 为 `.env` 并填写：

- `DEEPSEEK_API_KEY`：AI 问答、自动分析、报告、图像理解；
- `AMAP_KEY`：逆地理、周边 POI、高德底图；
- `CLOUD_TOKEN`：星图卫星影像（可选）。

模型名和 Base URL 固定在代码中；**换 Key 不会切换供应商**，切换模型需要改代码并重新验收。
本地 RAG 还依赖 `chromadb`、`sentence-transformers`、模型缓存和索引；状态接口会显示
“依赖检查 / 索引读取 / 索引构建 / 模型加载 / 实际检索”阶段。

## 4. 能力与边界

| 能力 | 前提 | 边界 |
| --- | --- | --- |
| 内置示例、质控、阈值筛查、图表 | 基础程序与数据 | 合成数据；不需要 LLM Key |
| 手工恒定流情景 | 参数与求解器 | 一维恒定流理想情景；不是当地已率定河道 |
| AI 问答、报告、图像理解 | 服务端 DeepSeek Key、权限、网络 | 失败时保留问题/附件/草稿并提示；不伪造回答 |
| 本地 RAG 检索 | 嵌入依赖、模型、索引 | 相似度不代表治理效果或责任概率 |
| RAG 综合回答 | 本地检索 + LLM | 区分“检索成功但回答失败”等阶段 |
| 国控/星图/高德/Esri/OSM | 服务可达与 Key | 地图失败不阻塞监测图表；离线只作位置/背景参考 |
| 视频帧与图片附件 | 本机解码与项目保存 | 最多 1000 帧、最长边 960px；图片不写入对话正文 |
| 项目保存/导出/导入 | 项目 schema 4 | schema 1—3 可读；旧应用不能读 schema 4 |

**明确不支持的近期路径**：潮汐/支汊/二维回流 Web 正式路径、HEC-RAS 自动调用、真实多源归因、
现场准确率或责任认定。示例中的“单源/双源”只是数据生成提示，不能当作源数量盲测准确率。

## 6. 数据、身份与安全

- **示例身份**：`data/samples/manifest.json` 固定 `data_kind=synthetic`；每份 CSV 的 SHA-256、字节数、行数、
  时间范围、坐标系与单位由 manifest 记录；`.gitattributes` 将 CSV 标记为 binary，防止换行转换破坏哈希。
- **缺测**：S06 保留原始空单元格；生产加载器另行生成观测掩码与插值，二者可区分。
- **项目保存**：示例 ID/版本/标题/来源写入 `df.attrs['sample_meta']`，随项目快照保存；导出/导入保留身份。
- **密钥**：`.env` 与 `.mcp.json` 未被 Git 跟踪；密钥检查 9/9；接口只返回“是否填写”，不返回值；
  RAG 状态已移除本机绝对 `index_dir`。
- **项目包**：schema 4 增加图片附件；导入校验路径、哈希、类型、尺寸和总量；schema 1—3 自动补空附件。
- **交付包**：打包器拒绝未提交源码、未跟踪文件和被跟踪的本机配置；包内不含 `.env`、用户项目、模型缓存或隐藏真值。

## 10. 故障排查

| 现象 | 处理 |
| --- | --- |
| 端口被占用 | `--port` 换端口；旧实例不会被自动终止 |
| 页面打不开 | 生产服务用 `http://127.0.0.1:<端口>/`；开发 Vite 只监听 IPv6，用 `http://localhost:5173/` |
| 本地接口 502 | curl/urllib 走了系统代理；本地请求加 `--noproxy '*'` 或禁用代理 |
| 改了后端不生效 | 本机可能残留监听套接字；`Get-NetTCPConnection` 核对后换端口 |
| `WQ_PYTHON` 路径错 | 启动器会明确报“解释器不存在”并退出 1，不会静默换解释器 |
| 知识库不可用 | 看页面“阶段”：依赖缺失 / 索引读取 / 索引构建 / 模型加载 / 实际检索 |
| 卫星图失败 | 检查 `CLOUD_TOKEN` 与网络；轨迹和监测数据仍可用，可切换备用底图 |
| AI 报认证/额度/超时 | 按提示核对 Key、账户、权限或网络；数据、选文、附件和草稿保留 |
