# 智能体任务进度、停止与恢复（Q03）

## 行为

智能对话新增本轮阶段、轮次、工具状态及耗时，不用固定百分比冒充动态规划进度。运行中可请求停止；网络或计算调用需要在检查点收尾，期间仍禁止替换数据、切换项目和重新分析。已产生的部分派生结果可能保留，停止不会回滚整个会话；完整报告的完成标记及未提交正文不会因此保留为本轮成功。

`/api/agent/run`提供进程内状态，`/api/agent/runs/{run_id}/stop`只作用于当前会话匹配的任务。已完成任务不被迟到停止请求改写。刷新页面可恢复当前任务状态与服务端已保存到会话中的历史；服务进程重启不自动续跑，后续从当前数据重新分析。

连接结束必须有明确的`done`或`error`事件；无终止帧、无效结束状态、非法JSON及UTF-8拆片异常均不能直接解释为成功。界面会核对服务端任务状态，在确认当前调用收尾前保留忙碌状态，避免重复执行。完成、部分完成、失败和停止分别显示，未完整提交的输出不能当作有效报告。

## 生命周期与边界

同步SDK及工具在单独工作线程执行，由工作线程持有会话操作锁，直到实际退出才释放。HTTP流断开只发出协作停止信号，不提前释放锁。事件队列最多256帧，断开后停止投递；即使最终正文已提交但队列已满，连接关闭也能释放工作线程。工具进度保留最近100项及累计调用数量；不把这些运行时锁、线程和事件写入项目包。

每轮有独立ID，前端还核对数据版本、项目与请求序号，防止旧轮询、旧流或迟到停止响应覆盖新任务。服务端在提交最终正文与完成标记时进行同一停止检查；取消中的报告不作为当前有效证据。常规对话成功与完整自动分析完成是不同状态，不能混为一谈。

模型主循环与报告请求关闭SDK自动重试，单个模型请求设置120秒超时。该超时不是整条工具链的总耗时保证；RAG加载、外部查询或数值计算仍可能需要各自收尾，不声称立即终止已发送的外部请求。

- 330项Python回归、67项前端测试及生产构建通过；字段、21项泛化、16项后端与9项密钥检查通过。
- 专项覆盖工具开始前停止、工具运行中停止、锁保持、数据版本变化、迟到停止、空正文、完成队列满时断开、响应发送前失败和初始化失败；保留原有生成器关闭须标记停止的回归契约。
- 前端覆盖UTF-8/CRLF/心跳、无终止帧、无效结束状态、迟到任务和停止响应；SSR检查运行中停止按钮、工具阶段及结束后提示。
- 真实HTTP与DeepSeek：4条明确仿真记录；第一轮进入模型阶段后请求停止，期间修改水质等级返回409；下一轮使用新ID实际调用`get_data_summary`并完成回答；再一轮直接断开连接后停止，数据保留且未标记完整自动分析完成。
- 实际浏览器：在独立临时会话选择4行仿真CSV、加载、正常摘要问答、点击停止及刷新恢复；停止后控件恢复，提示不再误称仍被锁定。长回答正文未逐句作科学结论验收。

测试中的远程协议模拟与实际HTTP/模型调用分开记录。没有新增现场标签，不报告检测准确率。完整记录见`validation/agent_progress_20261022.json`。

密钥检查曾将Q02记录内的归档SHA256值识别为可疑密钥。已核对该值确属包校验值，把详细校验记录保留在交付清单，仓库内只引用该记录；未降低密钥扫描规则。旧测试模拟器补充可选run参数，锁互斥断言保持；生成器第一帧关闭的原有失败已修复。
