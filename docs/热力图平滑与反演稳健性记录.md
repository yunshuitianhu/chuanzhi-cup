# 热力图平滑与反演稳健性记录

日期：2026-10-18。本轮继续执行可移植、通用河段情景方向，不恢复 HEC-RAS。

## 热力图显示

旧算法将原始指数先平均再截到色标上限，个别极高指数可把整个邻域推成最高色阶；4 CSS 像素栅格和透明度的硬平台又放大了色块边缘。

现在先按固定色标的 0～8 范围处理显示值，再用有限支撑高斯核加权平均。透明度连续淡出，栅格缩小为2 CSS像素，并在最高2倍设备像素比的画布中高质量缩放。邻域显示半径48 CSS像素，随缩放改变对应的地理范围，不是污染物实际扩散半径。无支撑区域保持透明，不跨越任意长缺测区补点。

这些处理不改动监测数据、污染判定或Top5排序；原始指数仍在Top5点位详情中显示。色斑表示有界色阶的邻域平滑，不能用来读取单点最大值，颜色变浅不等于监测污染数值下降。图例增加显示上限说明，删除聚类弹窗中把同一增强评分重复称作“内梅罗均值”的文字。

使用用户真实Excel的1805个点，按WGS-84墨卡托投影生成同一色标下的前后算法对照；灰网格仅为背景。这是独立算法渲染，未宣称完成实际浏览器视觉验收。底图瓦片加载状态与色层算法分开，调整色层不能修复外部底图网络问题。

## 反演拒绝条件

`river_model/inverse.py`仍只做已知排放时段、边界、水动力和反应参数的单源恒定流实验：

- 同一时间与桩号的重复记录拒绝参与独立证据累加，调用方应先合并并确认误差模型。
- 相对无源基线的加权残差平方和改善不足9时，标记`unidentifiable`。
- 按输入观测标准差归一化的残差均方根超过2时，标记`model_mismatch`。
- 最优负荷触及界限，或有多个残差平方和相差不超过2的近优源候选，分别标记`bound_limited`或`ambiguous`。
- 仅有一个合格候选时，再检查该源最优负荷的0.8倍和1.2倍。任一探测超出搜索界限，或残差平方和增加不足9，标记`load_unresolved`。

只有`identified_in_scenario`返回`estimate`；其它状态保留候选拟合与拒绝原因，估计字段为`null`。以上数值是独立观测与给定误差尺度下的工程筛查阈值，不是统计置信区间，也不保证负荷误差小于20%。实际误差尺度、观测相关性和物理参数均需独立核实。

## 压力实验

复现命令：`python scripts/validate_inverse_robustness.py`。输出`work/inverse-robustness/robustness.json`，预期约束不满足时返回非零退出码。

真值81断面/15秒，拟合41断面/45秒；32个训练观测、16个留出观测。三档噪声各8个固定随机种子，共24次；另加6个不利或混淆情景。噪声百分比均相对真值污染增量峰值，不是相对总浓度。

| 情景 | 次数 | 本次结果 |
|---|---:|---|
| 2.5%噪声 | 8 | 源位置恢复；负荷相对误差3.97%～6.73% |
| 10%噪声 | 8 | 源位置恢复；负荷相对误差0.06%～14.41% |
| 25%噪声 | 8 | 全部标记负荷未分辨，不输出估计 |
| 流速偏高30% | 1 | 残差门槛拒绝 |
| 背景氨氮偏差为污染增量峰值的50% | 1 | 残差门槛拒绝 |
| 候选遗漏真实源 | 1 | 残差门槛拒绝 |
| 负荷上界只有真实值一半 | 1 | 残差门槛拒绝 |
| 全部观测在排放前 | 1 | 无信息，不输出估计 |
| 未告知的1.5倍污染增量仪器增益 | 1 | 仍通过情景筛查，但负荷误差58.53%；已知盲点，未修复 |

30例均符合脚本声明的预期，但这包括**成功复现未解决的混淆盲点**，绝不等于30例均正确识别来源。原始三个不同尺度河段也重新通过：负荷误差5.86%、2.43%、1.23%，留出NRMSE为2.94%、1.36%、0.39%。这些数字仅适用于本次合成设置。
