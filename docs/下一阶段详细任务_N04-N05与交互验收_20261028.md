| 星图 | 一次底图加载 | 实际瓦片/权限状态；不能用配置绿灯证明加载成功 |
| 国控 | 一次按省份查询 | 实际数据来源、抓取/监测时间、离线降级状态 |

规则：

- 一次简短文本成功不能证明报告或视觉也成功。
- 仿真样本关联的真实企业/POI 只作背景资料，不能写成仿真污染的责任主体。
- 外部服务失败时不修改示例读数“配合结果”。
- 真实调用结果与 C/F 受控矩阵分开记录。
- 服务权限缺失、额度不足或无网时标待外部条件，并保留可继续执行的基础验收。

## 10. N05-C：本地 RAG 与离线专项

### 10.1 条件与既有实现

- 当前通过 `WQ_EMBEDDING_MODEL` 指向本地模型，通过 `WQ_RAG_INDEX_DIR` 指向索引。
- 嵌入模型是延迟加载，不是每次启动必下载。
- 索引、模型版本/维度、依赖和资料库必须匹配。
- 只复制数据库文件不等于离线检索条件完整。
- 本地检索和 LLM 综合回答分开判断。

### 10.2 验收矩阵

| ID | 条件 | 预期 |

| RG01 | 缺 ChromaDB/嵌入依赖 | 报依赖阶段问题，基础系统仍可用 |

| RG03 | 模型已准备但索引缺失 | 区分未构建/构建失败，不造案例 |

- [ ] 本地离线模型和索引的准备/重建步骤写清楚。

- [ ] 不修改用户原 .rag_index；复制到隔离索引或在新目录构建。
