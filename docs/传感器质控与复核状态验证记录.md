# 传感器质控与复核状态验证记录

日期：2026-10-19。完成离线走航的第一版质量复核链路，不改变污染筛查规则、指数、聚类、热力图读数与物理模型。本轮没有把质量标记变成自动剔除，也未宣称真实检测准确率提升。

## 方法与范围

新增 `quality_control.py`，对氨氮、溶解氧执行范围/格式、孤立突刺、持续近恒值、重复时间戳及采样空档检查。规则只读取当前监测表，不读取场景编号、样例文件名、污染源配置或逐点真值。

- 突刺使用前后独立观测，按真实时间间隔插值邻居基线；长空档、重复时刻、缺测和无效值打断上下文。
- 近恒值要求整段最大最小差在容差以内，并同时满足实际时长和独立时刻数，避免采样密集、重复记录或缓慢漂移被误当长平台。
- 缺测与原始输入无效分开；插值不得补成新的原始观测参与质控上下文。清洗前的数值/文本单独保存，检测输入保持已有清洗逻辑。
- 整段恒值回标和突刺判断使用未来邻居，是离线检查，不是已完成的实时检测器。尚不含多仪器联合校准、缓慢漂移识别、增益偏差辨识或人工复核工作流。

借鉴 NOAA/IOOS QARTOD 的质量标记与检查思路：[质量标记手册1.2](https://cdn.ioos.noaa.gov/media/2020/07/QARTOD-Data-Flags-Manual_version1.2final.pdf)、[溶解氧质控手册](https://cdn.ioos.noaa.gov/attachments/2018/08/QARTOD_DOSecondUpdate_final.pdf)和[ioos_qc官方实现](https://ioos.github.io/ioos_qc/_modules/ioos_qc/qartod.html)。本实现不是QARTOD认证，也没有将海洋观测默认门限当河道仪器标准。

标记含义：1为未触发已执行规则，2为上下文不足，3为需要质控复核，4为原始输入超出已支持范围或格式无效，9为关键指标缺测。聚合优先级4→9→3→1/2；逐指标检查和具体原因同时保留。标记1不代表仪器合格，标记3不代表已确认故障。

默认工程参数：最大相邻间隔60秒；恒值段至少60秒、5个独立时刻；氨氮/DO突刺门限1.0/0.5 mg/L；恒值容差均0.001 mg/L。参数未经传感器率定，应结合采样间隔、分辨率和校准资料调整，不能以仿真成绩倒推现场适用性。

## 页面、接口与项目保存

- 图表页新增“传感器质量复核”：并列显示原始阈值预警、预警中的复核数、全部复核数和关键缺测数。支持类别筛选、分页、时间/坐标、排序前导入记录编号及原始文本查看。
- 地图逐点弹窗和点查详情显示质量标记、触发原因与原始氨氮/DO值。污染色阶与绘图数值保持原口径。
- 技术页检测摘要、聚类复核点数、综合摘要、智能体上下文和最终报告使用相同质量统计。报告抬头由代码保留预警数与复核预警数，生成文本须明确二者不能互相抵消。
- 新增只读 `GET /api/analysis/quality`，按类别分页，不改历史、检测和模型；新增严格类型校验的 `POST /api/analysis/quality-config`，同会话互斥，候选计算成功后才应用。
- 网页可编辑本项目门限。更改后重算质量注记，污染分级、评分、簇成员不变；撤销旧报告完成标记、保留历史正文与河道模型。新参数随用户正常“保存项目/保存并导出”持久化，复用SQLite及项目包，无数据库迁移。
- 新上传表保留清洗前读数和原始文本。旧项目没有单独保存过原值时明确标注不可追溯，不把旧清洗结果冒充导入原值；重新上传原表前应先保存项目副本。

另以单条真实短排放、两条短排放、长期真实缺氧等构造反例。单点真实短排放与仪器突刺可以给出完全相同输入；长期真实缺氧也可能呈恒值。因此即使触发规则，仍保留全部污染预警。慢漂移不被误并为全段恒值，但当前没有识别慢漂移的能力。
