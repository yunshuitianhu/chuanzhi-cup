# 进入首页与水波效果（2026-11-04）

## 行为

- `/` 显示独立进入首页，使用用户提供的水滴图片，左侧标题为“水质溯源与检测助手”，提供“进入工作台”链接到 `/chat`。
- 原应用外壳原样移至 `frontend/src/WorkspaceShell.vue`，进入工作台时挂载；首页不挂载数据侧栏，也不执行工作台的 bootstrap。现有四个业务路径可直接访问。
- 启动脚本输出地址由 `/chat` 调整为 `/`。服务仍通过既有只读构建快照提供页面和资源，需构建后重启服务加载新版。

## 效果来源与实现

背景位移着色器与波纹实例算法改编自 [React Bits Ripple Distortion](https://reactbits.dev/animations/ripple-distortion)，原作者 David Haz，保留许可证于 `frontend/src/vendor/react-bits-LICENSE.md`。依赖固定为 `ogl@1.0.11`，移植部分用于本应用，不作为独立组件产品分发。

保持原图颜色；鼠标移动和点击生成扩散、消退的图像扭曲。文字和链接保持 HTML，方便阅读及键盘操作。限制波纹数量、渲染像素比和位移场分辨率，静止后停止请求动画帧，隐藏页面时暂停，卸载时释放监听器、观察器与 WebGL 上下文。图片始终作为静态底层；无法初始化/丢失 WebGL 上下文时退回静态背景。初始小于等于 600px 或偏好减少动态效果时不初始化水波。

水滴图片内的英文指标是用户图片的一部分，不是当前会话的监测结果。
