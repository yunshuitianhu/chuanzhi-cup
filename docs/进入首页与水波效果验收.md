# 进入首页与水波效果（2026-11-04）

## 行为

- `/` 显示独立进入首页，使用用户提供的水滴图片，左侧标题为“水质溯源与检测助手”，提供“进入工作台”链接到 `/chat`。
- 原应用外壳原样移至 `frontend/src/WorkspaceShell.vue`，进入工作台时挂载；首页不挂载数据侧栏，也不执行工作台的 bootstrap。现有四个业务路径可直接访问。
- 启动脚本输出地址由 `/chat` 调整为 `/`。服务仍通过既有只读构建快照提供页面和资源，需构建后重启服务加载新版。

## 效果来源与实现

背景位移着色器与波纹实例算法改编自 [React Bits Ripple Distortion](https://reactbits.dev/animations/ripple-distortion)，原作者 David Haz，保留许可证于 `frontend/src/vendor/react-bits-LICENSE.md`。依赖固定为 `ogl@1.0.11`，移植部分用于本应用，不作为独立组件产品分发。

保持原图颜色；鼠标移动和点击生成扩散、消退的图像扭曲。文字和链接保持 HTML，方便阅读及键盘操作。限制波纹数量、渲染像素比和位移场分辨率，静止后停止请求动画帧，隐藏页面时暂停，卸载时释放监听器、观察器与 WebGL 上下文。图片始终作为静态底层；无法初始化/丢失 WebGL 上下文时退回静态背景。初始小于等于 600px 或偏好减少动态效果时不初始化水波。

水滴图片内的英文指标是用户图片的一部分，不是当前会话的监测结果。

## 主标题逐字入场（2026-11-04）

按用户指定的 [React Bits Split Text](https://reactbits.dev/text-animations/split-text) 默认 rise 形式，主标题拆分为两行字符，逐字从下方 40px 淡入；单字时长 1.25s，错峰间隔 55ms，第二行延续第一行顺序。使用 Vue 字符节点与 CSS 关键帧实现该形式，未引入 React、GSAP 或其运行时分字逻辑。副文案和按钮轻柔跟进入场；动画结束后不保留 transform，避免覆盖按钮原有 hover 样式。标题使用完整 aria-label，装饰字符对辅助技术隐藏；减少动态效果时取消动画及等待。

类型检查、最终生产构建通过。按上文相同的 CI 包装器运行 S04 字段/会话头检查通过，视频与河道模型分支仍有相同跳过，未宣称全字段覆盖。本次纯展示调整未新增自动化用例或重跑全套前端测试。浏览器实际读取到字符延迟依次为 0～495ms，入场初期字符透明度各不相同，结束后全部 opacity=1、transform=none；背景水波仍 ready，进入工作台链接及主要导航正常。减少动态效果分支做代码审查，未做浏览器偏好模拟。

## Tech Text 替换与页脚精简（2026-11-04）

用户随后指定主标题使用 [React Bits Tech Text](https://reactbits.dev/text-animations/tech-text)，因此替换上一节 Split Text 主标题效果。改编官方 Canvas 2D 字形精灵、虚线轮廓、技术选框与标注、拖动和弹回算法；两行各自继承页面字体和字号，保留两行文案及完整的标题 aria-label。关闭无人交互时的自动扫过，鼠标经过/点击时触发。源码作者与许可证沿用上文 React Bits 声明。右下角“轻移鼠标，泛起涟漪”及其图标已删除。

`TechTextLine.vue` 管理动态加载及卸载；字体加载迟到回调在卸载后不触发重绘。普通 HTML 字符保留排版占位，Canvas 不可用、初始化失败或减少动态效果时显示静态文字。未新增依赖。

类型检查、生产构建、相同 CI 包装器的 S04 字段/会话头检查通过（视频与河道分支仍有上述跳过）。浏览器实测两行 Canvas ready、字符出现虚线轮廓和标注、控制台无 warning/error；页脚提示不存在。进入 `/chat` 后标题 Canvas 数量为 0 且主要导航可见，返回正常；390px 宽度下文档宽度 390px、两行效果均 ready，之后恢复默认视口。本次未重跑全部前端回归，未做 Canvas 故障/减少动态效果偏好的浏览器注入。
