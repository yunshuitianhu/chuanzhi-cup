# 检测算法校验与时空支持修复记录

2026-10-18。用户确认暂时没有人工复核标签或传感器校准资料，本轮执行规则、受控场景、真实样例回归与服务集成校验，不计算现场准确率、召回率或准确率提升百分比。

## 修复内容

1. 严重度权重按阈值从低到高覆盖。此前高阈值权重会被低阈值覆盖，Pi=6、11的权重均错误地落到1.5；现分别为2、3。
2. 时间支持度改为“有效观测支持的超目标时长/完整窗口时长”，使用相邻状态的梯形积分。重复时间不增加独立证据，超过观测空档门限的区间不填充，未超目标的点不接受邻点加权。走航的时间支持度不是某个固定位置持续污染的证明。
3. 空间支持度按有效相邻观测分段，遇缺测序号、非法GPS、定位跳跃、长采样空档断开；按距离段首的最大跨度计权，避免返航回到起点后跨度抵消为零。复制记录不能凑足最少支持点。连续段只扫描一次。
4. 聚类使用球面米制距离，并同时限制相邻点的时间差。同坐标、同时间的重复记录不重复计入DBSCAN密度；配置最少独立观测数为2时也会生效。缺GPS仍保留点级预警；有时间列却缺时间的点不桥接两个已知事件。邻接图过密时明确说明聚类未完成，保留点级结果。
5. 原始工程综合指数和时空增强排序评分分别输出。聚类、Top5与时间序列的颜色使用原始指数，报告不再将增强评分标为内梅罗原始指数。指数异常但未触发氨氮/DO阈值的点只计为“指数线索（非黑臭）”。
6. 首末采样时间差改标“首末观测跨度”，不能据此宣称期间连续超标；聚类空间跨度采用两次最远点扫描的近似值，显示半径不叫污染影响半径。
7. 检测结果增加算法版本。旧项目会提示重新检测；重新检测清除综合摘要、图表说明缓存，API与Agent路径均处理。保留原始数据、视频、历史对话和已有河道模拟，历史报告不会自动改写。

单点氨氮/DO筛查阈值和原始综合指数公式本轮保持不变。没有通过增大阈值、删除异常峰值、伪造阴性样本等方式制造更好结果。

## 真实样例与聚类差异

读取用户提供的1805行走航Excel，修复前后均为1230个阈值预警点，原始综合指数最高202.05，Top5原行索引均为1054、1052、1053、775、780。增强排序最高值从1815.72变为3631.96，主要来自严重度权重覆盖错误的修复；该分数不是浓度或概率。

独立对照：旧经纬度平面聚类与新球面距离的纯空间聚类均为7簇，簇大小均为52、230、45、13、12、167、711。启用30分钟相邻时间门限后，大簇711点分成68、5、481、157点四组，总计10簇；全部1230点仍有簇，无噪声点。样例没有同坐标同时刻重复记录，因此本次7→10来自时间门限，不能解释成新增3个真实污染源。

参数为可调整的工程门限：`AnalysisConfig.dbscan_eps_m`优先；未指定时将旧角半径0.0003°转换成约33.36m球面距离；最少独立观测默认5；相邻时间门限默认30min，设为None可仅按空间聚类；连续支持最大观测空档默认5min。时间门限限制邻接关系，DBSCAN传递连接后整簇首末跨度可能大于30min。当前Web使用默认配置，尚未增加这些参数的表单；门限没有通过现场标签率定。

## 仍需解决的准确性问题

当前是氨氮和DO的点级筛查。[《城市黑臭水体整治工作指南》](https://swj.wuhan.gov.cn/szy/202004/P020200506380692667954.pdf)第2.3节包含透明度、ORP及重复采样、点位和河段判定要求；不能用本项目两指标走航预警冒充完整水体定级。

原始工程综合指数中的DO单因子公式、pH分段口径、浊度经验参考值仍需单独标准化审查。本轮没有把它们改称经过标准认证的指数，也未凭空指定DO=0的仪器检出限。后续应结合[HJ2.3-2018官方标准资料](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/other/pjjsdz/201810/t20181024_665363.shtml)、仪器量程/检出限、校准记录明确计算口径，再做独立对照；异常峰值不能仅因看起来过高就删除。

没有人工复核标签时，可继续做边界、缺失、重复、时间/空间噪声和跨场景一致性验证；不能保证真实污染识别率。未来取得标签后，应按河流或独立巡航分组留出验证，避免把相邻点随机拆分造成评测泄漏。水动力正演、来源反演、视频识别不属于这轮检测权重修复的现场准确性验收范围。
