# Q17 整体性能与体验验收

> 日期：2026-10-28
> 构建：`1f97faa`（生产构建，隔离项目目录，S01 V2）
> 范围：四页加载、长历史、示例图表、地图热力开关、Q16 工作台整合后的本机受控验收。
> 结论：本机受控性能画像与整体体验验收已完成；真实用户、读屏器、真机触屏、Safari/低端硬件和现场性能仍未验证。

## 1. 方法

- 同一台 Windows 11 机器、同一 Chromium、同一生产构建、同一 S01 V2 数据。
- 每个页面使用新的浏览器上下文，`networkidle` 后再等待 500ms；记录导航耗时、资源传输/解码字节、DOM 节点、`longtask`。
- 长历史使用 Playwright 路由夹具：24 条消息、38,643 字符，明确标注为合成文本，不调用模型；其他 API 仍走真实服务。
- 示例图表使用真实 S01 载入后进入图表页；外部地图瓦片受网络影响。
- 地图热力开关点击两次，等待两个 `requestAnimationFrame`；计时包含两帧等待，因此只比较前后，不当作纯 JS 耗时。
- 3 次运行取中位数；样本量不足以给出稳定 p95，因此同时保留最大值/样本范围。

### 2.2 长历史

- 24 条消息，其中 12 条长回答；合计 38,643 字符。
- DOM 节点：4,363；滚动高度：74,156px；可视高度：398px。
- long task：2 次，合计 **104ms**，最大 **53ms**。
- 上滚后 `scrollTop=0`，没有被流式跟随强制拉回。

这说明当前 **未虚拟化** 的长对话在本夹具规模下可渲染/滚动；超过该规模未测，不把它写成无限长对话保证。

### 2.3 示例图表

- 图表页 DOM 节点：505。
- long task：2 次，合计 **164ms**，最大 **90ms**。
- 其中包含真实 ECharts、地图瓦片、热力层初始化；外部地图网络会影响结果。

### 2.4 地图热力开关优化

| 指标 | 优化前中位数 | 优化后中位数 |
| --- | ---: | ---: |
| 关闭热力 | 71.2ms | 63.4ms |
| 打开热力 | 115.1ms | 64.5ms |

实现：`TraceMap.vue` 缓存热力 Layer，开关时只切换画布 `display`，不再每次移除/重新添加并重算 1805 点栅格。半径/透明度或数据变化时仍会重建，保证显示正确。

Node 受控基准（1805 点、900×548、半径 26）：

- 单次热力栅格中位数 **50.7ms**；
- 三次立即重绘中位数 **154.5ms**；
- 三次调度合并后中位数 **51.0ms**；
- 5,300 字符 Markdown 渲染中位数 **1.75ms**。
