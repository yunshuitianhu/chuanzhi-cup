# 首轮改进记录

日期：2026-10-17。范围：先修复 Web 核心流程、证据可信度与运行可复现性。
此前《项目全貌说明.md》记录的是旧版本快照，以下内容说明本轮的实际变化。

## 已完成

1. 上传文件先解析、校验，再替换会话。解析失败保留旧数据及分析；空数据拒绝加载。
   CSV/Excel 解析和视频抽帧移入线程池；视频间隔增加边界校验。
2. 新数据、新视频和目标等级切换均增加分析版本号。前端据此清除旧对话和分析缓存，
   包括“重新上传但行数相同”的情况。单会话的写入任务互斥，避免分析中替换数据。
3. 时间序列阈值从当前等级的统一配置读取，溶解氧标为下限、氨氮标为上限。
   阈值线参与坐标轴范围计算，避免所有实测值超标时参考线被裁在画布外。
4. 补齐视频工具执行分支，无视频时返回明确跳过信息；声明视觉特征不能替代实测指标。
   六个河道工具接入 Web Agent，工具定义由 Web 和 Streamlit 共享。
5. 工具调用校验参数类型、必填项、枚举和声明的数值范围，内核 JSON 错误传递到 SSE。
   模式切换重建 system prompt，非法 JSON 参数不再静默变为默认参数。
   工具失败时不把自动分析状态标记为完成，达到轮次上限后的回答也写入历史。
6. 对话状态移入 Pinia，新增会话历史接口；路由切换保留正在接收的流，刷新后恢复服务端历史。
   修复流式内容修改原始对象而未触发 Vue 更新的问题，显示工具完成/失败状态。
7. 报告使用当前会话分析数据与成功工具返回的证据，不直接采用模型传入的摘要数字。
   综合摘要排除未验收潮汐工况的水动力和水质数值，保留限制说明；Agent 仅运行恒定流情景。
8. 高德 POI、逆地理请求统一从 WGS-84 转为 GCJ-02，POI 坐标返回时转回 WGS-84。
   请求坐标保留六位小数，缺失/非法 POI 坐标不再伪装成搜索中心。
9. 水质模型 CFL 判据使用最大绝对流速，覆盖正向流、反向流和混合流向。
10. ECharts 改为按需注册图表与组件；补齐 Web 直接依赖，前端默认代理端口统一为 8002。
11. 冒烟检查支持命令行路径/环境变量和本机样本发现，统一走真实数据加载器，
    不再编造样本时间；缺少样本时显式失败，检测与图表检查不再静默跳过。
12. README 补充项目介绍、架构、Windows 启动方法、回归命令和能力边界。

## 复现

```powershell
python -m unittest discover -s tests -p "test_*regressions.py" -v
python tests/browser_session_regression.py
python tests/后端接口检查.py
python tests/前端字段名检查.py
python tests/字段名一致性检查.py
python tests/逆地理识别降级链.py
python tests/数据完整性检查.py
python tests/密钥泄漏检查.py
python test_smoke.py "你的监测样本.xlsx"
python tests/river_model_验收算例.py
```

前端构建在 frontend 目录执行 `npm run build`。浏览器回归需要 Playwright/Chromium，
默认使用 18372/18373 端口，运行记录和截图放在被忽略的 work/ 目录中。

## 本轮未完成的部分

- 未重新推导或修复纯 Python 非恒定流求解器。潮汐页面仍是实验入口，不能据此作结论。
- 未接入 HEC-RAS 非恒定流生产路径，未改断面几何及潮汐振幅匹配规则。
- 坐标请求以 mock 验证转换契约，未在线对照重测实际高德候选结果或证明点位精度。
- 未做真实 LLM 端到端效果评测、真实视频标定、RAG 检索效果评测或干净机器全量安装验证。
- 原有多源列表依旧主要按来源权重排序，尚未升级为证据匹配评分；权重不是责任概率。
- TypeScript 迁移、异常点证据联动、复测建议界面、部署、参赛 PDF 和视频仍待后续推进。
- 会话仍在单进程内存中，服务重启会丢失，不具备正式多用户部署所需的完整机制。

新增检查通过不代表上述未完成能力已经实现。
