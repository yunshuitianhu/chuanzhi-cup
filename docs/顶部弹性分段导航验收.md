# 顶部 Rubber Segment 导航（2026-11-04）

按用户标注的顶部区域，采用 [React Bits Rubber Segment](https://reactbits.dev/micro/rubber-segment) 的滑块拉伸、延迟收缩和回弹形式。原作者 David Haz，许可证保留于 `frontend/src/vendor/react-bits-LICENSE.md`。以原生动画帧和弹簧适配 Vue，没有新增 React/Motion 依赖。

## 行为

- 四个业务页面共享浅青色分段轨道。滑块先拉伸跨过间隔，再落到新位置并收缩回弹；前景副本随裁切区域显示深色文字，避免过渡时文字与滑块颜色混在一起。
- 链接仍为真实 RouterLink，保留 href、aria-current、键盘和浏览器历史语义。以成功更新的 route.path 为选中来源；不在 pointerdown 抢先切换路由，不增加拖动切页行为。
- 侧栏开关和侧边问答继续执行原有操作，添加独立按压回弹。没有把这些按钮伪装成互斥页面选项。
- 快速切换替换旧动画；布局/字体变化重新测量；减少动态效果直接定位；隐藏页签停止过渡，卸载清理观察器、偏好监听和动画帧。
- 裁切副本全部 aria-hidden 且不拦截指针，焦点仍在真实链接；目标光标仍可吸附。移动端保持四个文字入口。
