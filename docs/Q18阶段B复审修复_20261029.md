## 1. 多帧缓存没有包含模型实际收到的时间/帧标签（P2）

**根因**：缓存键只有有序像素 SHA、问题和模型；多帧提示还包含服务器生成的帧号与 `time_sec`，模型正文可以合法引用这些标签。相同像素在不同时间/帧号下命中缓存时，结构化来源更新但正文仍带旧时间。

**修复**：
- 多帧缓存键增加有序 `(frame_id, frame_number, time_sec)` 标签；标签变化即重新请求模型。
- 单帧提示不含时间/帧标签，缓存键保持不含标签。
- 命中缓存时仍按本次已校验帧重建来源、帧号、时间、质量、作用域。

**回归**：`test_sequence_cache_includes_frame_labels_and_times`。第 0/1 帧与第 2/3 帧有序像素相同、时间 0/5 与 10/15 秒：模型调用 2 次，第二次 `cached=false`，来源时间为 10/15 秒。

## 2. 按帧号排序不能保证按实际时间发送（P2）

**根因**：`sorted(frame_ids)` 只排序数组下标；恢复/导入数据可能帧号与 `time_sec` 非单调，模型提示却声称按时间顺序，且结果允许第 1 张到第 2 张的时间变化。

**修复**：
- 加载后读取每帧 `time_sec`，要求为有限数值；缺失/非有限直接拒绝。
- 按帧号顺序加载后检查时间非递减；若时间倒退，返回 422“所选帧的时间顺序与帧号顺序不一致，请重新选择连续时间段”，不调用模型。
- 相同时间允许，按帧号稳定排序；预览与发送顺序一致。

**回归**：`test_non_monotonic_frame_times_are_rejected`。第 0 帧 10 秒、第 1 帧 0 秒经真实项目编解码后请求，仍被拒绝且不调用模型。

## 3. 单帧全空观察仍作为成功缓存（P3，遗留）

**根因**：单帧解析允许 `observations=[]`、`not_visible=[]`、`quality_notes=[]` 同时出现，并写入成功缓存。

**修复**：单帧无可见观察时，必须至少有一条 `not_visible` 或 `quality_notes` 原因；全空返回 502，不写缓存。带原因的空观察仍允许（前端显示“未形成可核对可见观察”）。

**回归**：`test_completely_empty_single_result_is_rejected_and_not_cached`；原有“带原因空观察通过”用例保持通过。
