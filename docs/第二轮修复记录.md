## 污染物质量更新

源项按质量速率、实际排放覆盖时长和单元水体体积换算浓度增量：

`新增质量[g] = 负荷[kg] × 1000 / 排放时长[s] × 本步实际覆盖排放时间[s]`

`浓度增量[mg/L] = 新增质量[g] / 单元体积[m³]`

同时将实际输移路径改为节点控制体积的面通量：迎风对流与扩散在相邻单元之间等量交换质量。
使用相邻断面距离定义控制体积，边界为半单元；显式子步同时受对流和扩散约束。
正反向流分别选择入流边界，出流质量计入账目。

输出在 `params.mass_balance` 中记录各组分的初始、注入、流入、流出、反应变化、最终质量及残差。
质量单位为 kg。反应变化与输移边界分别记录；反应中物种浓度降低并不被误当作输移质量丢失。
该账目证明离散过程的质量核算，不能代替反应动力学的现场标定或元素守恒验证。

- 本轮数值输出会改变，原因包括质量源项、边界交换、扩散稳定步长和有效观测校验。不能要求继续复现原先错误算法的浓度峰值。
