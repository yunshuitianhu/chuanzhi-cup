# 推理证据边界与报告修复记录

日期：2026-10-19。本轮完成 Vue/FastAPI 主链路的第一阶段改进，没有升级正演或反演物理内核，也没有宣称来源识别或现场准确率已经通过验收。

## 数据身份与持久化

- 上传识别文件名中的明确仿真标记，以及已知说明工作表前32行中「数据性质」字段。说明表的自由文本不成为模型指令，也不读取污染源真值作为检测输入。
- 数据身份区分仿真、文件声明观测、来源未核验；三者都不自动标记为已独立核验。声明实测也不能代替校准和人工复核。
- 身份保存在 DataFrame.attrs，沿用已有项目编解码器保存，无须数据库迁移。文件改名后仍能保留声明。旧项目可由已有文件名识别明确仿真标记；缺少声明的旧中性文件名保持未核验，需要重新上传原表恢复声明。
- 上传、状态、统计摘要、综合摘要、智能体系统上下文、报告抬头与侧栏使用一致身份。历史检测与摘要有证据版本检查，旧报告保留为历史并提示重新分析。

## 统计与解释

- 走航回归只输出沿航迹指数升高、降低或无明显变化，时间趋势标为未判定。没有固定地点的重复观测与时空分离，不推断水质恶化、改善或稳定。
- 删除误导性的「持续超标时长」和「超标倍数范围」字段，使用首末观测跨度、原始内梅罗范围与增强评分。新旧界面对应显示已调整。
- 全缺COD明确缺测。记录各数值列的原始观测标记，统计和Top5报告不把插值当原始观测；旧数据缺少标记时明确无法追溯。
- 无黑臭热点时仍报告有效GPS记录、轨迹起终点与全轨迹坐标包络。没有热点的原因明确为无氨氮/DO预警点参与聚类；往返起终点接近不表示覆盖范围小。
- 摘要明确当前黑臭筛查使用氨氮/DO，缺SD与ORP；COD不参与该项判定。正常点指数未在热点表展示，不表示没有计算。

## 溯源与报告约束

- 仿真分析的智能体跳过真实企业和国控背景归因查询，排除旧真实企业证据；技术展示页独立背景查询仍可用，返回仿真使用限制。
- 实际数据报告保留待核实企业线索，但不把数据源排序权重解释为来源概率。当前未核验同期、同一水文连通河段、可比采样条件，站点原始浓度不进入报告的直接比较；独立查询结果仍保留。
- 结构化证据明确已确认污染源为空、物理反演未接入报告。正演设定位置、质量、时段不能冒充识别结果。
- 报告身份、GPS记录数、预警数与结论级别抬头由代码生成。统一系统规则同时用于自动分析、对话和报告；案例仅借鉴治理思路。
- 实际复核发现旧2000 token上限会截断正文。现要求简明正文、提供4000 token余量，并检查结束原因；被截断、过滤或未生成正文时不返回成功报告。

这些约束减少了已复现的错误，不是对所有生成文本的语义正确性保证；成因解释和建议仍需复核。旧Streamlit独立编排未完成整套迁移验收，本轮主要交付 Vue/FastAPI 路径。

原机实际安装为ChromaDB 1.5.8、sentence-transformers 5.5.1，旧锁文件却指向0.6.3和4.2.0。本轮在索引副本上复现旧版本读取现有索引出现 `_type` 错误，已对齐这两项依赖。未把副本中的实验操作写回原索引。

知识库导入改为在真正检索时加载。缺依赖或索引读取失败时明确返回检索不可用，由HTTP接口返回503，不冒充空知识库或成功案例。报告实际未取得案例时也明确显示；这不意味着知识库功能可以省略验收。
