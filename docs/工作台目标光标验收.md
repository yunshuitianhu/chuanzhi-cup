# 工作台 Target Cursor（2026-11-04）

用户要求进入工作台后使用 [React Bits Target Cursor](https://reactbits.dev/animations/target-cursor)。采用官方四角目标框、弹簧吸附、自由旋转和点击收缩算法，移植到 Vue 的组件挂载/卸载；源码作者 David Haz，许可证见 `frontend/src/vendor/react-bits-LICENSE.md`。未引入 React 或新依赖。

## 行为与边界

- 仅在 `WorkspaceShell.vue` 挂载目标光标，通过 Teleport 显示到 body，`pointer-events:none` 不拦截点击。首页不挂载该组件。
- 吸附按钮、链接、summary、role=button 和显式 cursor-target 元素，采用工作台浅青色目标框。
- 文本输入、select、contenteditable、iframe、Leaflet 地图、ECharts 区域及禁用控件恢复原生光标。可通过 `data-native-cursor` 显式保留原生区域。
- 仅在可悬停的精细指针且未要求减少动态效果时启用；设备/偏好变化时重置。键盘操作、失焦、移出窗口时恢复原生光标；退出工作台清理全局监听、动画帧和隐藏光标样式。
- 不自动给按钮增加标签，不改变表单或分析流程。
