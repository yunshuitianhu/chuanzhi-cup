# 多河段仿真数据与多源排放验证记录

2026-10-18。用户要求在地图上选几处河道，设置一个或多个假定污染源，并按现有样本表格式制作仿真走航数据。

## 实现

`solve_water_quality` 新增末尾可选参数 `point_sources`，仅供受控脚本使用。每个事件给出组分、负荷、桩号、开始时刻、持续时间和可选源 ID。空列表为无排放对照；未传列表时保留旧单源调用。所有源按各自时间交集向同一控制体积注入质量，随后共同输移、反应，避免对非线性耗氧结果作简单叠加。

结果提供各事件的实际注入质量与离散位置。多事件情况下旧单源坐标等字段置空，避免默认为虚构中点。没有把多源反演开放到网页，也没有把源 ID 当作检测输出。

`scripts/generate_synthetic_monitoring.py` 不联网，不依赖用户会话或指定样本文件，使用固定地图描线、假定恒定水力条件与随机种子生成 JSON 中间数据、逐点 CSV 真值和 GeoJSON。输出目录必须为新目录，防止覆盖已有真值。Excel 另用 artifact-tool 导出。

## 数据设计

三处地图选点：南京秦淮河、成都南河、杭州瓶窑镇河道（河名未核实）。描线只供示意，非测绘中心线；流向和全部水力参数是假设，不以地名充当已率定参数。

六组、每组 1801 行、5 秒间隔：正常背景、单源持续、双源持续、单源两次间歇、两源氨氮/CBOD耗氧、正常背景叠加仪器异常和缺测。81断面，30秒积分外步长，模拟3.5小时，预热1小时后逐点时空走航取样。NH3/DO为物理模型输出；水温/pH/浊度/电量为经验辅助序列；电导率、COD、TOC留空，不把CBOD当COD。

首表保留现有样本的12列与文本时间格式，第二表标明仿真性质。污染源位置、负荷及无噪声逐点真值放在独立目录，输入表不包含答案。记录数、数值、缺测、时间及源配置可以独立核对。

## 验证

- 196项Python回归通过，其中新增5项验证：旧接口等价、多源分组分守恒及顺序、跨终点/未来事件、空源对照、无效事件拒绝。泛化能力21项通过。
- 六份Excel逐列回读数值一致，列名/顺序一致，无Excel错误单元格，时间严格5秒间隔，通过实际 `load_data` 与 `find_black_spots`。
- 无噪声阈值真值/当前筛查预警数：S01 0/0；S02 659/661；S03 1272/1271；S04 753/753；S05 249/250；S06 0/24。S02–S05分别有3/1、1/2、5/5、2/1个误报/漏报，同总数不等于逐点一致。
- S06故意加入的24个仪器异常均触发预警，36个关键指标缺测点不参与判定。未删除负例或改算法迎合本次样本。
- 单源S02产生3个热点簇，间歇单源S04也产生3个热点簇，不能用聚类数代替源数。来源识别没有运行。
- 原始表格式及每个新工作表均经渲染查看；三条近似路线与地图对照。未进行真实浏览器视觉验收。

## 限制

这是受控算法校验和演示数据，不是当地监测，不代表现场准确率。阈值标签与规则共享定义，正演与生成器共享物理模型，均不是独立外部验证。几何、流向、边界及反应参数未经现场率定；未涉及支汊、潮汐、二维流动或责任认定。交付数据包附带真值、使用说明及实际筛查结果，使用Excel不需要部署数据库或安装商业水动力软件。
