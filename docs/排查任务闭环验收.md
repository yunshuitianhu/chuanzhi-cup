# Q05 排查任务闭环验收

日期：2026-10-22。完成的是候选假设、复测计划和人工复核的记录流程。演示中没有实施现场复测，不证明检测准确率或污染责任。

## 功能与保存

- 智能对话页增加排查任务面板，可手工创建，或从当前报告统计卡片的支持记录加入。关联记录须由服务端核对所属会话、快照指纹及支持集合；过期或不属于报告的记录被拒绝。
- 每项记录候选假设、支持/反对依据、复测位置和指标、计划、带时区的实际记录、复核人、结果与剩余缺口。人工输入始终标为未独立核验；结果只有支持、不支持和无法区分，不提供“已确认责任主体”状态。
- 已安排复测须补齐位置、指标、计划；已记录复测须有带时区的时间和实际记录；复核/结束阶段须有依据、复核意见与显式确认。录入内容是否真实仍需要现场与人员核实。
- 绑定项目的修改使用现有 SQLite 索引及不可变项目快照自动保存；临时会话提示另存，切换项目时也会暂存只有手工排查任务的内容。新建空项目不带入旧任务。
- 请求同时核对数据/项目范围和排查版本，拒绝迟到写入或覆盖新版本。存储失败回滚任务变更。保存成功但刷新项目列表失败时明确区分两种结果，不重试写入。
- 数据、目标等级、分析或模型依据变化后，已复核/结束任务显示“依据已变化，需重新复核”。原始记录摘录保留，旧关联不用于当前地图；必须重新人工确认，才把复核依据更新到当前条件。
- 每个项目最多50项任务，每项保留最近20次修改。没有删除任务接口。重置分析保留任务；历史摘录、笔记及修改记录随项目导出和恢复。
- 项目包升级为 schema 2；旧 schema 1 严格匹配旧字段后迁移为空任务列表。schema 2 缺任务字段和格式错误时拒绝导入。新包需要新版程序，旧程序不能读取 schema 2。
