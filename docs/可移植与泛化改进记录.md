- **河段配置**：新增通用 `RiverConfig`、`generate_cross_sections`。旧名称仅保留兼容别名。初始模板不附带真实河名、坐标、集水面积或设计流量。页面可编辑长度、参考宽深、坡降、糙率、流量、局部高程及初始水质；另可展开设置 CBOD、水温、硝化/衰减速率、底泥耗氧和饱和 DO。参数随结果导出，未经现场率定。没有上传数据也可运行情景模型。
- **取消隐性套用**：缺少 GPS 时明确报错并引导手工配置；GPS 估计只读取当前 DataFrame，不再读取 `_uploaded_data.xlsx` 或固定样本。自动识别地名不会默认套用该河流的物理参考参数；无集水面积时不再使用 122.8 km² 占位值估流，而是以本次几何、坡降和糙率作曼宁公式情景估计。数据和 GPS 入口共用管道。卫星估宽不默认发起批量外部请求。
- **几何与水动力**：按水面交点计算部分淹没岸坡的湿面积、湿周和水面宽；查表范围随断面高程变化，消除固定 −5～5 m 高程限制。稳态初值与求解器中点摩阻方程一致，修复原约 1.7 mm 的初始漂移；保持旧验收阈值不变。非整步长/输出间隔的模拟保存真实终点，不静默截短。
- **地图渐变**：改用原始综合污染指数，固定颜色刻度，以邻域核权重求平均；采样密集不会累加成更严重的颜色。包含有效低污染观测，DO=0 保留。默认关闭聚类范围，可分别切换热力层、聚类和 Top5。原始指数与时空增强排序评分分别标注；图例随目标水质等级变化。没有观测支撑处透明，平滑区域不冒充实测。
- **国控证据**：多源查询改为按已核实省份请求实时 HTTP 服务，保留实际回退状态。技术页查询进入当前会话及综合摘要。记录查询条件、查询时间、抓取状态及监测时间；不以一次失败推断 API 普遍不可用，不把今天的站点值当作历史走航同日值。监测站不再参与排污企业候选排序。修复关键词筛空后返回全量、按省缓存被关键词污染，以及跨省模糊补坐标的问题。

## 尚未完成的泛化边界

当前为一维简化恒定流与理想梯形河段情景。实际不规则断面、干湿交替、支汊、快速流及二维/潮汐过程仍需专门方法和实测验收。自动位置/地形/河宽建议含区域或类型假设，不能视为“任意河流已自动率定”；真实使用须核实断面、边界、局部高程基准、反应参数、传感器误差和 GPS 桩号映射。国控离线目录也不代表所有省份都有完整的本地坐标覆盖。
